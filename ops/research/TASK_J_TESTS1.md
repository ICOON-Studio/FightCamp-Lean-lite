Kind: research

Status: OPEN (S370, Claude). Seat: John (real-world research). Discipline: boxing (amateur club, UK/England Boxing).

## Why
The operator (S370): "lets focus on the training and planning aspect, lets say a fighter doesnt want to compete just learn
and get stronger, faster etc how we make the player feel the goal and engage with it". Our goals today are abstract stat
changes ("+2.5 conditioning in 28 days"). The plan: every training goal becomes a TEST she takes on a date - a real test a
boxing coach would run - with a target number, a weekly check-in and a personal record. We never invent the numbers.

## Questions (answer each with sources - links, papers, England Boxing / coaching manuals; mark anything unsourced)
1. Which fitness and skill tests do real boxing coaches (amateur clubs, England Boxing coaching courses, S&C coaches for
   boxers) actually run? For each: what it measures (strength / power / speed / engine / skill), how it is done in a club
   (equipment, time), and how often it is repeated. Cover at least: punch output on the heavy bag (punches per round, per
   3-minute round, round 1 vs last round), punch force / power (force bag, accelerometer, kg or Newtons), hand speed
   (punches in 10 s / 30 s, speed bag hits), the multi-stage bleep test (levels), 1.5-mile / 3 km / 5 km run times,
   30 m sprint, press-ups / burpees / plank, skipping (skips per minute, double unders), reaction time, and skill checks
   (a coach marking a combination clean on the pads, footwork drills).
2. Typical VALUES for each test at four levels: a fit adult beginner who never competed; a club boxer (6-18 months);
   a carded amateur (20-50 bouts); an elite amateur / GB squad. Women and men separately where the sources split them.
3. How fast do the numbers move with training? Realistic weekly or monthly gains for a beginner and for a trained boxer
   (e.g. bleep level per 4 weeks, run time per month, punch output per month), and when they plateau.
4. Skill awards: does England Boxing (or the old ABA) run a graded skills award scheme for non-competing boxers (bronze /
   silver / gold, "Box Skills" or similar)? What does each grade test? Same for other countries (USA Boxing, Boxing
   Ireland, Boxing Australia) if there is one.
5. What do non-competing club members say keeps them coming (surveys, club articles, white-collar boxing): the goals they
   set themselves and how coaches mark progress.

## Deliver
A table per question (test | how | values by level | source), then 5 lines: the six tests you would pick for a game where
