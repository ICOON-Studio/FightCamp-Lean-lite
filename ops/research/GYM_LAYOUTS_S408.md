# The gym as the menu: layouts, bonuses and building your own (S408)

Operator S408: "make the fucking game look like a game not a website form", "Yes, paint it", "all 4 look nice", "maybe add option for player to select", "each gym slight bonus different from each other", "or even option to create their own later with preset assets or how other games do that".

## In the game now
scripts/ui/GymHub.gd leads Home: four painted isometric clubs (assets/ui/art/gym_hub_1..4.jpg), six clickable places each, a Layout button. The layout is a Settings value and has no effect on play yet.

## Next: a slight bonus per building (not built)
The choice must move from Settings to the career (Career field, saved), picked once at the "Your club" setup step with the four paintings as cards. The free Layout button goes: a free swap of bonuses is an exploit. A later change of building can be the existing Move premises buy.

Proposed, each read from what the painting shows. Numbers are starting points: measure with tools/ balance harness first, and read each hook in the rules before quoting them.

| Building | What it shows | Bonus |
|---|---|---|
| 1 Front of house | Big reception and lounge | New members join about 5% faster |
| 2 Two full rings with seats | Two rings, spectators | A club show earns about 5% more, or sparring gains a little |
| 3 The bag wall | Long bag row, big weights floor | Power and technique training about 3% better |
| 4 Conditioning floor | Large matted conditioning space, rehab room | Injured boxers back about 10% sooner |

Every bonus shows on its card as one plain line, and only if the rules run it.

## Later: build your own
Decided direction (old project lessons, memory MGT2 rooms drawn empty and draw the zone then the items): the player starts from an empty shell, draws zones on the isometric grid and places preset items. Needs isometric item art from Ludo (one set, same angle) and a tile grid over the floor. The four paintings then become ready-made starts. Enters only when the last build feels right (CLAUDE.md scope rule).

## Where design ideas come from
Pinterest for mood and layout; Game UI Database (gameuidatabase.com) for real game screens by genre and screen type; ArtStation and Behance for concept art. Ideas only, nothing copied.
