Detailed Specification of Critical Surfaces
1. Main Hall Floor (wood_cabinet_worn_long or parquet_clean_wood)
Visual Goal: High-density, professional tongue-and-groove maple sports court with a fresh commercial polyurethane gloss coating.
Base Color: #C48E56 tint over base albedo.
Roughness: Uniform 0.38. Clear-coat specular response highlights the long light streaks from the high windows and ring lighting without showing muddy diffuse scattering.
Normal Map: Strength 0.85. Individual 75mm plank seams are razor sharp; zero wood rot, zero gouges.
UV Layout: Vector2(1.0, 1.0) meters per tile repeat. UV aligned parallel to the 30.0m front cutaway wall to maximize longitudinal perspective depth.
2. 18-Foot Boxing Ring Canvas (fabric_pattern_07 / canvas_tight_weave)
Visual Goal: High-tension 24-ounce cotton duck combat canvas, clean factory finish.
Resolution: 2048×2048 (single dedicated 2K texture for crisp close-ups and ring camera orbit).
Base Color: #E5E7EB (Subtle warm combat grey-white). Center ring printed insignia with real-time screen-space decal blending.
Roughness: 0.88 diffuse cloth scattering.
Normal Map: Strength 1.20. Clear tight orthogonal textile weave with double-needle flat-felled seam lines running parallel at 1.8m intervals.
Decal Sub-layer: Center club roundel emblem (1024×1024 PNG) applied via Decal node (albedo_mix = 0.95, normal blend 0.4).
3. Ring Skirt & Apron (tarp_pvc_clean)
Base Color: #111827 (Matte Obsidian).
Roughness: 0.42 (Glossy synthetic vinyl tarp).
Normal Map: Vertical drape tension creases every 0.6m; reinforced perimeter hem with brass eyelet ring grommets at 0.45m spacing.
4. Corner Posts, Turnbuckles & Ropes
Posts (4): Heavy-duty 100mm diameter schedule-40 steel tubing. Red corner post #DC2626, Blue corner post #2563EB, Two neutral posts #1F2937. Metallic 0.85, Roughness 0.22.
Ropes (4 tiers): 28mm steel aircraft cable sheathed in high-gloss hygienic vinyl covers. Top rope #DC2626, Middle ropes #FFFFFF, Bottom rope #2563EB. Normal map reproduces longitudinal extrusion seam.
Turnbuckle Pads (12): High-density impact foam sheathed in heavy vinyl wrap. Padded wedge design, corner matched colors, high-contrast strap tie-downs.
5. Station Mats (The 1-Second Visual Read Zones)

To satisfy the 1-second zone identification rule from the high camera angle, each zone features distinct, high-contrast floor boundary mats:

Cardio Zone Mat: Hex #1E3A8A (Deep Royal Blue). Rubber gym matting. 1.0m interlock tile pattern with a 25mm safety bevel edge in #F59E0B (Safety Amber).
Strength Zone (Rack & Platform): Hex #18181B (Charcoal Black) 20mm vulcanized rubber deadlift drop tiles with an inset Olympic lifting wood core (#D97706).
Stretch Zone: Hex #0284C7 (Cyan Blue) EVA foam closed-cell mats. Smooth micro-stippling normal map.
Footwork Zone: Hex #D97706 (Amber Ochre) polyurethane court mat with screen-printed white agility ladder grids (500mm × 400mm rungs).
Heavy Bag Track Floor: Continuous 2.0m-wide #374151 dark grey textured rubber runner along the left wall under the heavy bags.
6. Back Brick Wall & Branding Elements
Brick Masonry: Running bond structural red brick (#8B4513), clean grey-white lime mortar seams (#CBD5E1). Zero efflorescence, zero cracking.
Club Sign ("ANVIL STREET GYM"): CNC cutout acrylic letterforms pinned 40mm off the brick surface on steel standoffs. Face color #F8FAFC, edge depth 15mm #334155. Integrated backwards cast shadow and localized emissive edge backlight.
Commercial Wall Clock: 600mm industrial circular chronometer. Black spun-aluminum housing (#090D14), matte white face (#F8FAFC), green high-luminescence digital split seconds display (#22C55E, Emission Energy 2.5).

SECTION C: POST-PROCESSING & GODOT 4.7 RENDER PIPELINE

To achieve the 2026 AAA management look (crisp sports-broadcast quality with photographic depth), configure the WorldEnvironment node with the following exact parameters:

# FightCamp Gym Floor Camera WorldEnvironment Settings
# Target: 60 FPS on GTX 1660 / RTX 3050 Class Hardware

[environment]
tonemap_mode = 3 # ACES Filmic Tonemapping
tonemap_exposure = 1.05
tonemap_white = 1.0

# 1. Screen-Space Ambient Occlusion (SSAO)
ssao_enabled = true
ssao_radius = 1.8
ssao_intensity = 2.4
ssao_power = 1.5
ssao_detail = 0.6
ssao_horizon = 0.06
ssao_sharpness = 0.98

# 2. Screen-Space Indirect Lighting (SSIL)
ssil_enabled = true
ssil_radius = 3.5
ssil_intensity = 1.2
ssil_sharpness = 0.9

# 3. Screen-Space Reflections (SSR)
ssr_enabled = true
ssr_max_steps = 48
ssr_fade_in = 0.15
ssr_fade_out = 0.8
ssr_depth_tolerance = 0.2

# 4. Glow / Bloom (Photoreal Thresholding - No 80s Neon Hazing)
glow_enabled = true
glow_normalized = true
glow_intensity = 0.45
glow_strength = 0.85
glow_bloom = 0.0
glow_blend_mode = 0 # Additive
glow_hdr_threshold = 1.15 # Only unclipped specular and emissive fixtures pop
glow_hdr_scale = 1.8

# 5. Volumetric Fog (Atmospheric God-Rays from High Clerestory Windows)
volumetric_fog_enabled = true
volumetric_fog_density = 0.008
volumetric_fog_albedo = Color(0.95, 0.92, 0.88, 1.0)
volumetric_fog_emission = Color(0.0, 0.0, 0.0, 1.0)
volumetric_fog_emission_energy = 0.0
volumetric_fog_anisotropy = 0.65 # Forward Mie-scattering concentrates shafts toward camera
volumetric_fog_length = 28.0
volumetric_fog_ambient_inject = 0.15

# 6. Global Illumination (Baking Strategy)
# Production Recommendation: Baked LightmapGI with high-density LightmapProbes (1.5m grid)
# Realtime Override (RTX/High): SDFGI Enabled (Cascades: 4, Cell Size: 0.25m, Y-Scale: 75%)
