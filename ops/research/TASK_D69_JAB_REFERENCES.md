# D69 - reference jab clips that set the bar (Dola, S231)

Fresh eyes, research only. Our boxing game's jab animation was rejected by our CEO ("I have never seen worse animation
of a jab"). We need the bar for the replacement.

Name THREE reference sources for a textbook boxing jab that we can legally use as motion reference (or buy/download as
motion data): for each give
- the source (motion-capture library entry, coaching video, or broadcast fight moment) and a link,
- its licence (free / paid / reference-only),
- what the lead foot, the rear hand and the head do at the moment of contact.
Prefer real mocap data (e.g. a mocap library boxing pack) over video. Names and sources only - never invent a link;
say UNKNOWN when a source does not state something.
