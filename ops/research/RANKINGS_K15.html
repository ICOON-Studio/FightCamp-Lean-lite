A–G RULINGS (SHORT)

A · OWN RAIL ITEM RANKINGS. Route exists; rail forgot it — bug, not verdict. Rejected WORLD hub (orgs/events already lean SCHEDULE/OFFICE; bundling delays the APIs that exist). Rejected SCOUTING tab (ranked ≠ available). Rejected dissolve into division asks (no home when not mid-ask).

B · DEFAULT = focused fighter’s division (discipline × weight × sex). Sex locked to ladder. Player asks for other class/discipline, P4P, Champions. No four controls before a name.

C · ROW: # · silhouette · name · record · move ↑↓— · belt if champ · vs-ours (AHEAD/BEHIND/OUR) · gym/world mark. Leave off: bookable, wage, full stats, scouting affordability.

D · OURS: OUR chip + gold edge + auto-scroll. Empty gym first-career: calm strip, world ladder still shown, FIND OURS disabled — not BAD.

E · PRESS: ours → fighter card; world → read-only peek / scouting candidate VIEW only — never MAKE OFFER from rankings (ranked ≠ available). Nothing if no card.

F · CHAMPIONS: tab of this board (not own, not strip-only). K7 owns crowning. Vacant stays vacant.

G · KIT GAPS: ranking_row · ladder_scope · our_in_ladder · belt_holder_row · vacant_belt_state · empty_gym_ranked. Reuse tab_bar, filter_strip, pair, badge, alert_strip, silhouettes. No drag.

GAMESTATE READ GAPS: movement delta / prior-week snapshot not named in TASK APIs; is_ours / gym membership on ranking entries; focused-fighter division helper for default open. Existing: get_division_rankings · get_p4p_rankings · get_championships · get_champion_superfight_offers.
