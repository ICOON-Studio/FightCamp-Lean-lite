# K24 — THE YEAR TURN — WHERE THE YEAR IS SHOWN

**Claude acts on this:** THE YEARS shows on surfaces that already exist — never a new rail. Birthday = quiet age on profile HERO; THE DAY ticker only for roster champions or the week's focused fighter (not thirty spam lines). Decline is never the word "declining" — only the shape of existing numbers/instruments. Retirement is an ASK (attention + ACTION ROW), answered with room (R45 precedent), not a vanish. Finished career (G9 epilogue) is READ on the retired fighter's profile; not nowhere; not a new OFFICE destination.

No new rail item (K10 standing). No new UIKit factory. No new token. Reference existing: ShellChrome, attention strip, news ticker, ProfileRevampPanel HERO / ACTION ROW, UIKit.squad_row, _push_news, ask system, R45 post-fight precedent. Maria owns visual language (M11).

## 1. Birthday

**Question:** Where and how loudly does a fighter's birthday surface when the year turns?

**Options considered:**
- (A) Every roster birthday on THE DAY
- (B) Never an event — number only
- (C) Selective feed

**Ruling: C — selective feed.**

- Profile HERO age always updates quietly (silent number change for everyone).
- Feed / news ticker line only when the birthday is the player's focused fighter that week **OR** the fighter holds a belt (champion / interim) on the roster.
- Everyone else: silent number change only — no ticker spam.

**Why:** Thirty birthdays a year would drown THE DAY; silence for everyone hides the year turning on people who matter.

```
THE DAY
  [attention strip] ...
  [news ticker]  optional: "Champ X turns N" / focused fighter only
PROFILE HERO
  age · (always quiet update)
```

## 2. Decline

**Question:** How does the game show a fighter past peak without teaching the wrong relationship?

**Options considered:**
- (A) Label DECLINING / PAST PEAK on profile
- (B) News headline "X is declining"
- (C) Numbers only

**Ruling: C — numbers only.**

Never print "declining" / "past peak" / "washed". Peak age is felt through existing instruments — stats / condition / medical on profile, UIKit.squad_row heat, ACTION ROW needs — not a status chip.

**Why:** A manager game that insults the roster with a wash label teaches the wrong relationship; the year already shows in the numbers R51 will move.

## 3. Retirement

**Question:** How does retirement arrive, and what happens on yes / no?

**Options considered:**
- (A) Auto-remove from gym
- (B) Modal popup
- (C) ASK via existing ask system with room on yes

**Ruling: C — ASK + room.**

Retirement arrives as an ASK (R51). Surfaces: THE DAY attention strip + fighter ACTION ROW (same seam as medical / contract asks). Player chooses between the authored options R51 delivers (do not invent choices).

- **On YES:** give the moment room — set-piece / full-bleed beat in the spirit of R45 post-fight (not a one-line toast), then the fighter leaves the active roster into the finished-career profile state.
- **On NO / defer:** ask clears per ask rules; no punish popup.

**Why:** Vanish is dishonest; interrupt popup breaks THE DAY grammar; an ask is how this game already handles player-owned decisions.

```
THE DAY
  [attention] RETIREMENT ASK · ...
PROFILE ACTION ROW
  [retirement ask chip] beside medical / contract
```

## 5. Finished career / G9 epilogue

**Question:** Where does the player read a finished career (G9 epilogue)?

**Options considered:**
- (A) Nowhere until player digs in a menu
- (B) New OFFICE archive destination
- (C) On the retired profile itself

**Ruling: C — on the retired profile.**

Primary read = profile of someone who no longer fights — HERO / body shows G9 fields (years active, peak year, defining win, epitaph) when present; honest empty when G9 not yet filled. OFFICE does not need a new archive hub for v1 (drill-in from roster history later is enough if Claude adds a "former" filter — optional follow-on, not this stage).

**Why:** The relationship was with the person; the profile is where you already go to know them.

```
PROFILE (retired)
  HERO: age · retired state
  body / epilogue: years active · peak year · defining win · epitaph
                  (honest empty if G9 unset)
```
