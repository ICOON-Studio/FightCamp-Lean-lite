## DECISIONS
1. Treat one UE scene set as the paired move: one track per role, one montage clock.
2. Selection is authored order; every non-null criterion on the candidate must pass.
3. Normal joining uses one initiator-derived start time; late join is a separate explicit path.
4. UE distances are centimetres; angles are degrees; animation times are seconds; forward is +X.
5. Alignment/IK caches sample at the asset SampleRate (default 15 fps), not an assumed 30 fps.
6. Code wins over comments: late join starts at 0.0 s and does not request montage sync.

### P1
`FContextualAnimSet` stores tracks (one per role), baked warp-point transforms, a name, and
RandomWeight. Each `FContextualAnimTrack` stores Animation, AnimMaxStartTime, movement/rotation
controls, optionality, MeshToScene, selection criteria, alignment data, IK target data, and role/
section/set/track indices. The asset has sections (named groups of sets) and PrimaryRole; the
two-actor binding maps the declared primary role to the primary context and every other role to
the secondary context. A track's authored root is `ExtractRootTransform(animation,t) *
MeshToScene`; alignment stores that root relative to the set warp point. Precompute uses
`SampleInterval = 1 / SampleRate` and samples `t = clamp(index*interval,0,play_length)` until the
animation ends. IK precompute similarly stores the source bone relative to the target-role bone.
Citations: P1.

### P2
`FindFirstAnimTrackForRoleThatPassesSelectionCriteria` scans `AnimSets`, then each set's
`Tracks`, and returns the first track for the requested role whose criteria all pass; a null
criterion is ignored. No candidate returns null/false. Distance criterion uses
`Dist2D(primary.location,querier.location)` or 3D `Dist`, then inclusive
`MinDistance <= distance <= MaxDistance`, in cm. Thus `MaxDistance=0` is not an unbounded
maximum; it accepts only exactly zero distance (and MinDistance=0 includes zero). Cone first
requires 3D distance <= Distance (cm), then compares a 2D direction dot product with
`cos(clamp(radians(HalfAngle),0,pi))`; Offset/HalfAngle are degrees. ToPrimary tests
querier->primary against querier forward; FromPrimary tests primary->querier against primary
forward, with Offset applied around +Z. Criteria run in their array order and short-circuit.
Citations: P2.

### P3
The authoritative normal start path calculates one `IdealStartTime` from the owner/initiator,
then calls `JoinScene` for the owner and every other binding with that same seconds value;
when disabled it is 0.0 s. `Montage_Play(..., StartTime)` starts each montage at that position.
If the section enables sync, a non-leader montage calls `MontageSync_Follow(LeaderMontage)` once
inside play setup; the sync leader is the binding returned by `GetSyncLeader`, so followers track
the leader rather than each other. This is not a per-tick manual lock. The ideal search compares
2D cm distances to the first warp section's end/sync location, samples at 1/30 s, and stops at
`WarpEndTime - FindIdealStartTimeMargin`; `AnimMaxStartTime > 0` additionally caps candidate
times in the asset legacy search. `LateJoinScene` calls `PlayAnimation_Internal(...,0.f,false)`:
the code does not advance it to the current montage time or attach it to the sync leader.
Citations: P3.

### P4
Each motion-warping notify supplies a named warp target and a trigger interval. UE derives the
runtime target from the primary actor (or its named socket, or a custom weighted point between
roles), then computes `relative_alignment_at_warp_end * warp_point_world_transform` and adds
that transform under the notify's name. The warp window is the named motion-warping notify's
trigger-to-end time; repeated same-name windows resolve to the latest ending one. On join, the
component installs collision behavior and the track's movement mode; it can ignore other actors,
channels, or replace the collision profile, disable physics, and disable character rotation
controls. Leave restores saved responses/profile, movement mode, rotation, replication and
movement-correction state. All transforms/distances are UE cm-space; times are seconds.
Citations: P4.

### P5
`FContextualAnimIKTargetDefinition` names the IK goal and source BoneName, selects Provider,
TargetRoleName, and TargetBoneName. For Autogenerated, precompute samples source component-space
bone * source MeshToScene relative to target-role component-space target bone * target
MeshToScene (or target role origin when target bone is unavailable), at `1/SampleRate` seconds.
At runtime, each pose update gets the current montage position and multiplies the cached relative
transform by the target actor's current target-bone socket transform. Bone provider instead uses
that socket transform directly. If target animation is expected but not active, alpha becomes
0. IK alpha is 0 outside the notify; inside, it linearly/custom-curved blends 0->1 for
`BlendIn` (default 0.25 s), holds 1, then blends 1->0 across the final `BlendOut` (default
0.25 s), using the notify's trigger/end times and duration.
Citations: P5.

### P6
The early-out notify ticks only for a locally controlled character with non-zero last input;
it calls `EarlyOutContextualAnimScene(bStopEveryone)`. That may call `LeaveScene` on all actors
or only the caller. Montage blend-out removes the montage from the played list and, when none
remain and `CanLeaveScene` permits (base returns true), calls `LeaveScene`. Leaving stops the
montage, unhooks notify/tick callbacks, restores collision and movement state, removes warp
targets, clears IK/bindings, and notifies the other actors.
Citations: P6.

### FOR OUR BOXING PAIRS
1. Query a jab/head set for the fighter roles; its authored-order candidate wins only if all criteria pass.
2. For a distance criterion, test the current fighter locations with 2D or 3D `Dist` in cm; 1.0-1.5 m means 100-150 cm. Mark facing/cone results as INFERENCE unless the asset criterion is authored.
3. Bind A to `PrimaryRole` and B to the other role; calculate the primary/socket/custom warp point from their current transforms.
4. Add each named warp target using each track's alignment transform at the notify end; warp each actor during that notify window.
5. Start both montages at the same initiator-derived seconds time (normally 0.0 s unless ideal-start is enabled); the non-primary follows the sync leader if `bSyncAnimations` is true.
6. At the contact/IK notify, evaluate the cached A-glove-to-B-head relative transform at the current time and apply it to B's live head socket; blend alpha in/out as authored. Exact contact frame, asset choice, and boxing bone names are INFERENCE/data, not decided by this code.
