1. Rule-by-Rule Audit
1.1 Pro Corner Logic vs. Corner Colors (§1.2)
Verdict: KEEP (APPROVED).
Operational Reason: Amateur boxing forces red/blue singlets, which completely erases fighter individuality and branding. Nevada Administrative Code (NAC 467.437 / NRUC 4.020) and ABC explicitly mandate personal trunks with commission approval against clashes. Retaining red/blue exclusively for the UI Scorebug, Stool, Bucket, and Coach Jacket accents is standard for HBO, Showtime, and DAZN broadcasts.
1.2 Contrast Thresholds (§1.3: $\Delta E_{00} \ge 20$, WCAG $\ge 1.5:1$, Waistband Structure)
Verdict: KEEP, BUT HARDEN R2.
The Problem: WCAG $1.5:1$ between trunk bases is too forgiving when fighters clinch. Under the warm 3200K linear multiply (#ffb674), low-luminance chromatic differences collapse.
The Fix: Raise R2 to WCAG luminance contrast $\ge 2.2:1$ between trunk base colors, OR enforce that if luminance contrast is $< 2.0:1$, the waistband must differ by WCAG $\ge 4.5:1$ (strict black vs. pure white).
1.3 Canvas & Crowd Rules (§1.3: E1, E2, E3)
Verdict: KEEP.
Enforcing dark waistbands for light trunks and light waistbands for dark trunks prevents boxers from dissolving into the #cfcac2 canvas or #1c1916 crowd.
1.4 Boot Tint Rules (§3)
Verdict: MODIFY.
Flaw in M43: Tinting the boot shoe base identical to the trunk base color (e.g., Crimson trunks + Crimson boots) creates visual clutter. On a 1080p wide broadcast shot, high boots of the same color as the shorts visually shorten the legs and muddy the fighter's stance width.
The Fix (Classic Heavyweight Rule): Boxing boots should be predominantly neutral (Matte Black #121212 or Optic White #F4F4F2), using the kit color strictly as an accent on the Laces, Ankle Strap, and Heel Counter. Only K04 Black and K03 White may run solid monochrome boots.

5. Automated Matchmaking Clash Algorithm (GDScript Implementation)

Programmers can drop this directly into res://scripts/combat/kit_resolver.gd.

class_name KitResolver
extends RefCounted

const DELTA_E_THRESHOLD: float = 22.0
const LUM_RATIO_THRESHOLD: float = 2.0

# Pre-computed clash lookup table (True = CLASH, must switch away boxer to Alt)
# Matrix evaluates: DeltaE00 < 22 under warm 3200K lighting OR severe CVD confusion
const CLASH_MATRIX: Dictionary = {
	"K01_K12": true, # Crimson vs Maroon (Hue overlap under warm key)
	"K01_K07": true, # Crimson vs Green (Severe Deutan failure: dE00 < 6.0)
	"K04_K06": true, # Black vs Purple (Crowd baseline failure)
	"K04_K10": true, # Black vs Steel Charcoal (Low luminance separation)
	"K05_K09": true, # Gold vs Orange (Converges to identical amber under 3200K)
	"K02_K06": true, # Royal Blue vs Purple (Protan confusion)
}

static func resolve_matchup(home_boxer: Fighter, away_boxer: Fighter) -> void:
	var home_kit: String = home_boxer.assigned_kit_id
	var away_kit: String = away_boxer.assigned_kit_id
	
	# Rule 1: Exact kit match always clashes
	if home_kit == away_kit or _is_clash(home_kit, away_kit):
		# Switch away boxer to their designated alternate kit
		var alt_kit: String = KitRegistry.get_alt_kit(away_kit)
		
		# Rule 2: If the alternate also clashes with home, force universal safe kit (K03 White or K04 Black)
		if alt_kit == home_kit or _is_clash(home_kit, alt_kit):
			if home_kit == "K03":
				alt_kit = "K04" # Home is white, away takes black
			else:
				alt_kit = "K03" # Away defaults to optic white
				
		away_boxer.active_bout_kit = alt_kit
	else:
		away_boxer.active_bout_kit = away_kit

static func _is_clash(kit_a: String, kit_b: String) -> bool:
	var key_1: String = kit_a + "_" + kit_b
	var key_2: String = kit_b + "_" + kit_a
	return CLASH_MATRIX.get(key_1, false) or CLASH_MATRIX.get(key_2, false)

1. Section-by-Section Audit of K87
Section 1 (The 45s Corner Flow): KEEP, WITH PACING TWEAK.
The transition from 3D bell to broadcast camera cut must be snappy. 1.0s is good. 45 seconds is authentic to the unified rules of boxing (which mandate 60s total: 15s clear-out, leaving 45s for seconds).
Section 2 (Camp Focus $\to$ Default Call): KEEP (BRILLIANT DESIGN).
Tying the corner call directly to what the player drilled in the gym during the 5-week camp closes the core loop: Gym Planning $\to$ Fight Execution.
Section 3 (Visible AI Response in Round 2): KEEP.
This is mandatory. If changing the call does not visibly alter punch output, step distance, and clinch frequency, the management loop collapses into a numbers spreadsheet.
Section 4 (Corners 2+ & Progression): MODIFY.
Correction: In Fights 2 to 4, do not prompt a disruptive modal pop-up ("SIM TO RESULT?"). Instead, place the Auto-Send Toggle directly onto the corner card chassis at all times.
Section 5 (Failure Guards): PASS.
Kalli’s three guards (Too Slow, Ignored, Feels Fake) are solid. Guard 2 is reinforced below with explicit visual weight.

3. UI Implementation: Visualizing "From Camp" Without a Tutorial Modal

We must teach the player that this decision was already made in the gym without popping up an intrusive tutorial box that breaks immersion:

The Gold Rail (StyleBoxFlat Left Border):
The Default Call card has a thick, $4\text{ px}$ vertical left border in pure radiant gold (#E5B842).
The other two cards have a $1\text{ px}$ dark border (#3D3126).
The Source Badge:
A pill badge sits at the top-left of the active card:
Icon: res://ui/icons/tent_gym_camp.svg ($14\times 14\text{ px}$, gold tint).
Text: "CAMP DIRECTIVE" in 10pt bold uppercase cream.
The Connection Tooltip:
Hovering over the badge shows a 1-line tooltip:
"Set during Week 3 Camp Focus: Hook Mastery. Gives +15% power to inside hooks."
Card Swapping Behavior:
Clicking either of the other two alternative calls instantly moves the gold rail and the active glow to that card.
The badge text dynamically updates to: "CORNER AUDIBLE (TACTICAL OVERRIDE)" in amber (#D69E2E).
The player immediately learns: Gold = My Preparation; Amber = In-Fight Adjustment.
