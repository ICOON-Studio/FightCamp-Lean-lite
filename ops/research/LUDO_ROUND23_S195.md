## Claude's verdict (operator to decide on the board)
Today's build already answers "too small": hall 20 x 12 -> 20 x 18 (+50%), weights moved clear, open strip for more stations (commit 2220fd29). Ludo's 28 x 20 is the ELITE-tier size; it gives a natural growth path
that fits the career/legacy loop Ludo itself asked for in R21 (garage start -> established club -> elite centre), with the hall data-driven by tier. Widening to 28 m also means a wider front block (rooms, street): a
bigger data job but still data, with the same test gates. Recommendation: keep 20 x 18 as the starting hall, make 28 x 20 the upgrade the manager buys (hall expansion = a money sink with a visible payoff), and take
Ludo's footprints and adjacency rules as the placement rules for new stations (ring apron 1.8 m, bag rig swing 0.9 m, spine 2.2 m). Nothing of the 28 m hall is built yet.
