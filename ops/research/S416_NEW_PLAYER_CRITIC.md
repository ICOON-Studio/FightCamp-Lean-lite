One question: "What should Lucy do next round?" with 3 big cards (Calm down / Fire up / Tell the truth), each with a plain result ("+1.2 power next round, tires her 5% more"). 3. Recovery with big + / - buttons and a counter. 4. A big "Start round 2" button always visible.
2. Playbook: add a "Coach's suggestion" on every line: "Best against walks-you-down: Step back (worked 3 of 3)" and a one-click "Use suggestion".
3. Write every stat as a sentence with a unit: "Luke's pad sessions make boxers improve 30% faster". No bare "+30%". Ban numbers without a noun.
4. Every page gets a plain top line: "This is where you [verb]." plus one highlighted next button.
5. A permanent "What to do this week" checklist (Set training, Book a bout, Start the camp, Write the plan, Weigh in) that opens the right page.
6. Move Mail to a labelled top-bar button with a number, and mark the one message that needs an answer.
7. Split Money in three tabs: This week (cash, bills), Buy (the shop), People (hires - remove from here). Show 6 numbers on the first.
8. Replace jargon: tell -> habit, file -> scouting report, gap -> experience gap, edge -> bonus, lines -> tactics.
9. Every greyed button gets a reason on the button itself ("Needs 4 wins").
10. The guide bubble: never covers page content; only talks about the current page; a "Show me" button points to the control with an arrow.
11. Title: hide Resume when no career exists; one sentence under each start mode.
