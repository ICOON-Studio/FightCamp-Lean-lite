# C179 Character Creator physique generator

Proof CSV is generated by `python Tools/cc_bridge/physique_table.py --roster` from the 100-athlete featured roster. The complete CSV is included below in the committed digest.

## Formulas

- `girth = clamp(sqrt(weight_kg / (23 * (height_cm/100)^2)), 0.85, 1.30)`.
- Build-B slider values are scaled linearly from zero at girth 0.85, pinned at baseline at girth 1.0, and reach 2x baseline at girth 1.30; all values are clamped before CC application.
- Male Skinny is `clamp((1-girth)/0.15, 0, 1)`. Shoulder Width A is `clamp(0.10 + 1.5*(reach_cm/height_cm - 1), -1, 1)`; missing reach is neutral.
- Height uses Character Scale A and the build-A 93 cm/unit slope, fitted against the current avatar bounds.

The operator-generated `Tools/cc_bridge/out/build_a.txt` and `probe2.txt` were absent from this checkout, so exact CC-discovered ranges could not be re-read; the implementation records conservative ranges and documents this calibration limitation. No export was run.

## Operator steps

1. Create `Tools/cc_bridge/in/athlete.json` with id, name, sex, height_cm, weight_kg, reach_cm, and class_limit_kg.
2. In CC, open the avatar and use Script > Load Python on `Tools/cc_bridge/build_from_athlete.py`; inspect `Tools/cc_bridge/out/<id>_build.txt`.
3. If acceptable, load `Tools/cc_bridge/export_athlete.py`; it refuses duplicate IDs and refuses after 29 spent exports.
4. Confirm `Godot/assets/models/fighters/cc/<id>.fbx`; Godot resolves it through `CCFighterSkin.cc_export_for(id)`.
