A training day runs as a state machine divided into four distinct phases spanning a 24-hour cycle. Each phase processes fatigue, skill acquisition, injury risk, and coach supervision in sequence.

1. Dawn Aerobics (06:00 – 08:30)
Focus: Aerobic capacity, lower-leg conditioning, weight management.
Stations Active: Roadwork perimeter, jump rope bays.
Energy Draw: $12%$ to $18%$ of baseline energy tank.
Metrics Affected: Aerobic Base ($+0.12% \text{ to } +0.28%$), Acute Fatigue ($+8%$).
Coach Role: Unsupervised or conditioning coach check-in.
2. Primary Morning Session (09:30 – 12:30)
Focus: Main technical and physical focus set in the Weekly Planner (BAGS, RING, STRENGTH, CARDIO).
Stations Active: Sparring ring, heavy bag rows, iron pit.
Energy Draw: $35%$ to $52%$ of baseline energy tank.
Metrics Affected: Primary focus attribute ($+0.35% \text{ to } +0.65%$), Micro-trauma ($+12% \text{ to } +24%$).
Coach Role: Direct 1-on-1 instruction or group supervision.
3. Afternoon Secondary & Tactical (14:00 – 17:00)
Focus: Mitt-work, film review, speed bags, neck bridge, or physiotherapy recovery.
Stations Active: Speed bag racks, floor mats, hydrotherapy tank, doctor’s clinic.
Energy Draw: $15%$ to $30%$ of baseline energy tank.
Metrics Affected: Technique/sharpness ($+0.15%$), CNS fatigue ($+10%$).
4. Night Repair & Sleep Consolidation (20:00 – 06:00)
Focus: Recovery, neuromuscular adaptation, psychological settling.
Stations Active: Bunkhouse, recovery clinic.
Energy Draw: Net positive ($+45%$ to $+80%$ energy recovery).
Metrics Affected: Acute fatigue decay ($-70%$), carry-over fatigue accumulation ($+5% \text{ to } +15%$ if overtrained).

Modifier Calculations:

Coach Competency Multiplier ($\text{CoachMod}$):
$$\text{CoachMod} = 0.50 + \left(\frac{\text{CoachSkill}}{100}\right) \times 0.75 \quad (\text{Range: } 0.50 \text{ to } 1.25)$$

If coach has trait MASTER_PADMAN and station is SPARRING_RING: additional $+15%$ synergy.
If station is unstaffed: $\text{CoachMod} = 0.40$ (self-directed penalty).

Readiness Multiplier ($\text{ReadinessMod}$):

$\text{Readiness} \ge 80%$: $1.10\times$ (Flow state bonus).
$50% \le \text{Readiness} < 80%$: $1.00\times$ (Nominal rate).
$30% \le \text{Readiness} < 50%$: $0.65\times$ (Sluggish mechanics).
$\text{Readiness} < 30%$: $0.20\times$ (Exhaustion breakdown, zero skill gains).

Camp Intensity Modifiers:

LIGHT: $0.60\times$ gain, $0.40\times$ fatigue, $0.15\times$ injury risk.
MEDIUM: $1.00\times$ gain, $1.00\times$ fatigue, $1.00\times$ injury risk.
HEAVY: $1.35\times$ gain, $1.65\times$ fatigue, $2.40\times$ injury risk.
MAX: $1.60\times$ gain, $2.40\times$ fatigue, $4.80\times$ injury risk.

Acute Fatigue Generation:
$$\Delta\text{Fatigue}_{\text{acute}} = \text{BaseStationBurn} \times \text{IntensityMod} \times (1.0 - \text{Conditioning} \times 0.003)$$

Roadwork: $+12$
Heavy Bags: $+26$
Sparring: $+38$
Weights: $+32$
Speed Bags / Pads: $+16$

Overnight Acute Dissipation:
$$\text{Fatigue}{\text{acute, morning}} = \max\left(0, \text{Fatigue}{\text{acute, night}} - (\text{SleepQuality} \times 70)\right)$$

Systemic Spillover Formula:
Whenever acute fatigue exceeds $70$ at bedtime, excess spills directly into persistent systemic exhaustion:
$$\Delta\text{Systemic} = (\text{Fatigue}_{\text{acute, night}} - 70) \times 0.45$$
Systemic exhaustion permanently caps maximum daily readiness:
$$\text{MaxReadiness} = 100 - \text{Systemic}$$

PART 4: REFUSAL, FRICTION & CRISIS TRIGGERS

Fighters do not mindlessly obey training schedules. Each day, an obedience/cooperation roll is performed. If friction triggers, the fighter refuses work or demands an audible change.

Refusal Risk Calculation:

$$\text{RefusalScore} = (\text{Fatigue}_{\text{systemic}} \times 0.60) + ((100 - \text{Morale}) \times 0.40) + \text{EgoPenalty} - (\text{CoachAuthority} \times 0.35)$$

Ego Penalty:
Boxer is Rank 1-10 Contender and assigned to ROADWORK: $+25\text{ refusal pts}$.
Boxer has PRIMA_DONNA trait and trains on unstaffed station: $+35\text{ refusal pts}$.
Assigned coach has lower prestige than boxer: $+20\text{ refusal pts}$.
Resolution Events:
Concede to Boxer: Convert today to RECOVERY or REST.
Consequence: Morale $+6$, Systemic Fatigue $-10$, Schedule broken, Coach authority $-5$.
Crack the Whip (Discipline): Force the scheduled workout.
Consequence: $50%$ chance workout completes at half efficiency; $50%$ chance boxer storms out, injury risk tripled ($3.0\times$), Coach-boxer bond damaged.
Bring in Head Coach for 1-on-1: Requires Manager/Head Coach action point.
Consequence: Nullifies refusal, converts workout into high-intensity breakthrough session.

PART 7: FULL GDSCRIPT MODULE IMPLEMENTATION

Below is the complete, self-contained implementation of the daily execution engine:

# res://scripts/sim/TrainingDayEngine.gd
class_name TrainingDayEngine
extends RefCounted

signal interval_started(interval_index: int, interval_name: String)
signal fighter_session_resolved(fighter_id: String, summary: Dictionary)
signal day_cycle_completed(day_number: int, ledger: Array)
signal refusal_event_triggered(fighter_id: String, refusal_data: Dictionary)

enum Interval {
	DAWN_AEROBICS = 0,
	MORNING_PRIMARY = 1,
	AFTERNOON_TACTICAL = 2,
	NIGHT_RECOVERY = 3
}

const INTERVAL_NAMES: Array[String] = [
	"Dawn Aerobics (06:00 - 08:30)",
	"Morning Primary Session (09:30 - 12:30)",
	"Afternoon Tactical & Clinic (14:00 - 17:00)",
	"Night Repair & Sleep (20:00 - 06:00)"
]

# Base attribute gain coefficient
const BASE_GAIN_RATE: float = 0.006

# Run full resolution for one fighter across a 24-hour training day
static func process_fighter_day(fighter: Dictionary, day_plan_focus: int, intensity: int, coach: Dictionary) -> Dictionary:
	var result_summary := {
		"fighter_id": fighter.get("id", "boxer_unknown"),
		"name": fighter.get("name", "Unknown Boxer"),
		"focus_id": day_plan_focus,
		"refusal": false,
		"attribute_deltas": {},
		"fatigue_start": fighter.get("fatigue_acute", 10),
		"fatigue_end": 0,
		"systemic_start": fighter.get("fatigue_systemic", 5),
		"systemic_end": 0,
		"readiness_next_day": 100,
		"coach_note": ""
	}

	# 1. Check for refusal / friction
	var refusal_chance: float = _calculate_refusal_risk(fighter, day_plan_focus, coach)
	if randf() < refusal_chance:
		result_summary["refusal"] = true
		result_summary["coach_note"] = "Boxer balked at assignment. Demanded altered schedule."
		# Process minimal rest workout
		fighter["morale"] = clampi(int(fighter.get("morale", 75)) - 8, 0, 100)
		result_summary["fatigue_end"] = fighter.get("fatigue_acute", 10)
		result_summary["systemic_end"] = fighter.get("fatigue_systemic", 5)
		result_summary["readiness_next_day"] = clampi(100 - int(fighter["fatigue_systemic"]), 20, 100)
		return result_summary

	# 2. Rest / Recovery Focus Handling
	if day_plan_focus == TrainingConstants.Focus.REST or day_plan_focus == TrainingConstants.Focus.RECOVERY:
		_process_rest_cycle(fighter, day_plan_focus, result_summary)
		return result_summary

	# 3. Active Workout Execution
	var coach_mod: float = _calculate_coach_modifier(coach)
	var readiness_mod: float = _calculate_readiness_modifier(fighter)
	var intensity_mult: float = _get_intensity_multiplier(intensity)

	# Determine targeted primary and secondary stats
	var focus_config: Dictionary = TrainingConstants.FOCUS_DATA.get(day_plan_focus, {})
	var primary_attr: String = focus_config.get("primary_attr", "power")
	var secondary_attr: String = focus_config.get("secondary_attr", "stamina")

	# Compute Diminishing Gains
	var cur_pri_val: float = float(fighter.get(primary_attr, 50))
	var cur_sec_val: float = float(fighter.get(secondary_attr, 50))

	var gain_pri: float = BASE_GAIN_RATE * pow(1.0 - (cur_pri_val / 100.0), 1.35) * coach_mod * readiness_mod * intensity_mult * 100.0
	var gain_sec: float = (gain_pri * 0.40)

	fighter[primary_attr] = clampf(cur_pri_val + gain_pri, 1.0, 99.9)
	fighter[secondary_attr] = clampf(cur_sec_val + gain_sec, 1.0, 99.9)

	result_summary["attribute_deltas"][primary_attr] = gain_pri
	result_summary["attribute_deltas"][secondary_attr] = gain_sec

	# 4. Fatigue & Medical Compounding
	var base_burn: int = int(focus_config.get("burn_cost", 25))
	var acute_burn: int = int(float(base_burn) * intensity_mult * (1.0 - (float(fighter.get("stamina", 50)) * 0.003)))
	var total_acute: int = int(fighter.get("fatigue_acute", 0)) + acute_burn

	# Overnight sleep clears up to 75% acute fatigue
	var remaining_acute: int = clampi(total_acute - 75, 0, 100)
	var current_systemic: int = int(fighter.get("fatigue_systemic", 0))

	# Spillover to systemic if acute was deep into the red (> 70)
	if total_acute > 70:
		var spillover: int = int(float(total_acute - 70) * 0.45)
		current_systemic = clampi(current_systemic + spillover, 0, 100)

	fighter["fatigue_acute"] = remaining_acute
	fighter["fatigue_systemic"] = current_systemic

	result_summary["fatigue_end"] = remaining_acute
	result_summary["systemic_end"] = current_systemic
	result_summary["readiness_next_day"] = clampi(100 - current_systemic - (remaining_acute / 2), 15, 100)

	# Generate tactical coach commentary
	result_summary["coach_note"] = _generate_coach_dossier_text(fighter, primary_attr, gain_pri, current_systemic)
	return result_summary

static func _process_rest_cycle(fighter: Dictionary, focus: int, out_summary: Dictionary) -> void:
	var acute_drain: int = 40
	var systemic_drain: int = 8

	if focus == TrainingConstants.Focus.RECOVERY:
		# Physiotherapy / Cryo / Massage accelerates recovery
		acute_drain = 65
		systemic_drain = 18

	fighter["fatigue_acute"] = clampi(int(fighter.get("fatigue_acute", 0)) - acute_drain, 0, 100)
	fighter["fatigue_systemic"] = clampi(int(fighter.get("fatigue_systemic", 0)) - systemic_drain, 0, 100)
	fighter["morale"] = clampi(int(fighter.get("morale", 80)) + 4, 0, 100)

	out_summary["fatigue_end"] = fighter["fatigue_acute"]
	out_summary["systemic_end"] = fighter["fatigue_systemic"]
	out_summary["readiness_next_day"] = clampi(100 - int(fighter["fatigue_systemic"]), 30, 100)
	out_summary["coach_note"] = "Rest & regeneration completed. Soft tissue inflammation subsided."

static func _calculate_refusal_risk(fighter: Dictionary, focus: int, coach: Dictionary) -> float:
	var sys_fatigue: float = float(fighter.get("fatigue_systemic", 0))
	var morale: float = float(fighter.get("morale", 75))
	var coach_authority: float = float(coach.get("authority", 50))

	# High systemic exhaustion combined with low morale triggers refusal
	var risk_score: float = (sys_fatigue * 0.50) + ((100.0 - morale) * 0.40) - (coach_authority * 0.30)

	# Extreme hard work when exhausted guarantees friction
	if sys_fatigue > 55 and focus != TrainingConstants.Focus.REST and focus != TrainingConstants.Focus.RECOVERY:
		risk_score += 35.0

	return clampf(risk_score / 100.0, 0.0, 0.85)

static func _calculate_coach_modifier(coach: Dictionary) -> float:
	if coach.is_empty():
		return 0.40 # Self-directed training penalty
	var coach_skill: float = float(coach.get("coaching_skill", 60))
	return 0.50 + (coach_skill / 100.0) * 0.75

static func _calculate_readiness_modifier(fighter: Dictionary) -> float:
	var readiness: int = int(fighter.get("readiness", 80))
	if readiness >= 80:
		return 1.10
	elif readiness >= 50:
		return 1.00
	elif readiness >= 30:
		return 0.65
	return 0.20

static func _get_intensity_multiplier(intensity: int) -> float:
	match intensity:
		TrainingConstants.Intensity.LIGHT: return 0.60
		TrainingConstants.Intensity.MEDIUM: return 1.00
		TrainingConstants.Intensity.HEAVY: return 1.35
		TrainingConstants.Intensity.MAX: return 1.60
	return 1.00

static func _generate_coach_dossier_text(fighter: Dictionary, stat_name: String, gain: float, systemic_fatigue: int) -> String:
	var boxer_name: String = str(fighter.get("name", "Boxer")).split(" ")[0]
	if systemic_fatigue >= 50:
		return "%s was dragging late in the rounds. Systemic fatigue is compromising form; schedule rest soon." % boxer_name
	elif gain >= 0.35:
		return "Superb technical retention. %s registered exceptional work on %s today." % [boxer_name, stat_name.to_upper()]
	else:
		return "Solid, disciplined output. Drills executed to standard without biomechanical breakdown."
