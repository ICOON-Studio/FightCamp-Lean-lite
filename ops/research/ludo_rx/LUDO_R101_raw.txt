PART A — JAB REVIEW & THREE REAL REFERENCE JABS (PAUL / Q-S231-2)
1. Is Round 95 the Version to Wire, or Does It Need Another Pass?

The Round 95 numbers are mathematically sound for animation blending trees, but they require one critical architectural pass before passing Paul's side-by-side bar (Q-S231-2):

The Retraction Must Be Asymmetrical (Faster Than Extension): In r95, extension and retraction were tuned with balanced easing curves. A real boxing jab snaps out in ~120-140ms but must snap back in ~90-110ms—retraction must be roughly 1.25x faster than extension. If retraction is symmetric or slower, the jab looks pushed rather than snapped on camera.
Rear-Hand "Phone Booth" Discipline: In the r95 contact pose, the rear glove stayed at static guard coordinates (X: 0.18, Y: 1.45, Z: -0.22). On the game camera, this looks detached. At full extension, the rear glove must actively glue its thumb knuckle to the zygomatic arch (cheekbone) while the rear elbow clamps tightly against the liver/ribs.
Lead Shoulder Elevation (Chin Tucking): At contact, the lead shoulder must rise by +42mm to bury the chin behind the deltoid. Without this, the head looks exposed and bobbing rather than anchored.
Lead Foot Plant & Kinetic Heel Drop: The lead foot must not simply translate forward; the heel drops firmly 15ms before knuckle contact to transfer ground reaction force up through the kinetic chain.
2. The Three Real Reference Jabs for Side-by-Side Review
Reference 1: Larry Holmes (The Piston Range-Finder & Snap Retraction)
Bout / Source: Larry Holmes vs. Gerry Cooney (June 11, 1982) — Round 2, Broadcast Master (04:18 on the official HBO classic archival reel / YouTube timestamp 04:18 - 04:22).
What Ours Must Match:
Retraction Speed: Holmes' jab retracts faster than it travels outward. The fist snaps back along the exact same optical trajectory without dropping an inch below the eye-line.
Rear Hand Guard: Rear glove stays glued to the right jawline with zero drift while the lead arm fires like a hydraulic piston.
Chamber: The lead elbow flares zero degrees; it travels in a completely straight vertical corridor from guard to target.
Reference 2: Gennady Golovkin (The Power Stiff-Jab & Heel Plant)
Bout / Source: Gennady Golovkin vs. David Lemieux (October 17, 2015) — Round 1, HBO PPV (Timestamp 02:44 - 02:48 of the round, or 09:12 on the full bout tape).
What Ours Must Match:
Lead Foot Plant: Golovkin takes a short 3-inch step with the lead toe, and the lead heel clicks into the canvas milliseconds before the punch lands, stiffening the whole frame.
Shoulder Elevation & Hip Turn: The lead shoulder raises into the jawline, while the lead hip rotates inward by 18 to 22 degrees, delivering heavy stopping power rather than just a range-finder tap.
Torso Lean: Zero forward pitch; head remains strictly behind the center of gravity.
Reference 3: Katie Taylor (The High-Cadence Kinetic Jab & Living Guard Transition)
Bout / Source: Katie Taylor vs. Amanda Serrano I (April 30, 2022) — Round 3, DAZN Broadcast (Timestamp 01:14 - 01:18 of the round).
What Ours Must Match:
Fluid Living Guard Transition: The punch fires effortlessly out of continuous micro-feints and head slips without telegraphing shoulder pre-tension.
Female Anatomical Center of Gravity & Elbow Corridor: Demonstrates the tight elbow track and thoracic rotation calibrated for female fighter skeletal proportions without clipping the chest or rib cage.
Immediate Recovery: Instant return to high tight guard ready to roll or fire the trailing right cross.

func setup(plan: Array, ctx: Dictionary, rules: Object, board: Object) -> void:
	_rules = rules
	_board = board
	_ctx = ctx.duplicate(true)
	_current_plan = plan.duplicate(true)

	_populate_templates()
	_refresh_board_headline()
	_rebuild_rows()
	_recalculate_cost()


func _populate_templates() -> void:
	_template_option.clear()
	var templates: Dictionary = Dictionary(_rules.get("TEMPLATES"))
	var keys: Array = templates.keys()

	_suggested_template = String(_rules.call("suggest", _ctx))
	var selected_idx: int = 0

	for i in range(keys.size()):
		var t_name: String = String(keys[i])
		_template_option.add_item(t_name.replace("_", " ").capitalize(), i)
		_template_option.set_item_metadata(i, t_name)
		if t_name == _suggested_template:
			selected_idx = i

	_template_option.select(selected_idx)


func _refresh_board_headline() -> void:
	var cur_template: String = _get_selected_template_key()
	var days_to_fight: int = int(_ctx.get("days_to_fight", 7))
	var title_str: String = String(_board.call("headline", cur_template, days_to_fight))
	_headline_label.text = title_str


func _get_selected_template_key() -> String:
	var idx: int = _template_option.selected
	if idx < 0:
		return _suggested_template
	return String(_template_option.get_item_metadata(idx))


func _on_template_selected(index: int) -> void:
	var t_key: String = String(_template_option.get_item_metadata(index))
	var templates: Dictionary = Dictionary(_rules.get("TEMPLATES"))
	if templates.has(t_key):
		_current_plan = Array(templates[t_key]).duplicate(true)
		_refresh_board_headline()
		_rebuild_rows()
		_recalculate_cost()


func _rebuild_rows() -> void:
	for c in _rows_container.get_children():
		c.queue_free()

	var row_models: Array = Array(_board.call("rows", _current_plan, _ctx))

	for i in range(_current_plan.size()):
		var block: Dictionary = Dictionary(_current_plan[i])
		var model: Dictionary = Dictionary(row_models[i]) if i < row_models.size() else {}
		_build_row_widget(i, block, model)

func _on_station_changed(item_index: int, row_index: int) -> void:
	if row_index < 0 or row_index >= _current_plan.size():
		return
	var row_node: Node = _rows_container.get_node("Row_%d" % row_index)
	var st_opt: OptionButton = row_node.get_node("HBoxContainer/StationOption") as OptionButton
	var new_station: String = String(st_opt.get_item_metadata(item_index))

	var res: Dictionary = Dictionary(_rules.call("audible", _current_plan, row_index, {"station_kind": new_station}))
	if bool(res.get("ok", false)):
		_current_plan = Array(res.get("plan", _current_plan)).duplicate(true)
		_recalculate_cost()


func _on_cue_changed(item_index: int, row_index: int) -> void:
	if row_index < 0 or row_index >= _current_plan.size():
		return
	var row_node: Node = _rows_container.get_node("Row_%d" % row_index)
	var cue_opt: OptionButton = row_node.get_node("HBoxContainer/CueOption") as OptionButton
	var new_cue: String = String(cue_opt.get_item_metadata(item_index))

	if bool(res.get("ok", false)):
		_current_plan = Array(res.get("plan", _current_plan)).duplicate(true)
		_recalculate_cost()


func _on_coached_toggled(pressed: bool, row_index: int) -> void:
	if row_index < 0 or row_index >= _current_plan.size():
		return
	var res: Dictionary = Dictionary(_rules.call("audible", _current_plan, row_index, {"coached": pressed}))
	if bool(res.get("ok", false)):
		_current_plan = Array(res.get("plan", _current_plan)).duplicate(true)
	else:
		# Rollback checkbox visually if audible refused it
		var row_node: Node = _rows_container.get_node("Row_%d" % row_index)
		var check: CheckBox = row_node.get_node("HBoxContainer/CoachedCheck") as CheckBox
		check.set_pressed_no_signal(not pressed)
	_recalculate_cost()


func _recalculate_cost() -> void:
	var cur_stamina: float = float(_ctx.get("stamina", 100.0))
	var cur_strain: float = float(_ctx.get("strain", 0.0))
	var cost_data: Dictionary = Dictionary(_rules.call("cost", _current_plan, cur_stamina, cur_strain))

	var end_stamina: float = float(cost_data.get("stamina", cur_stamina))
