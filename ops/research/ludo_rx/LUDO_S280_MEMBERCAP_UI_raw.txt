1. HOW TWO POINT & MAD GAMES TYCOON 2 SHOW CAPACITY LIMITS
Two Point Hospital / Two Point Museum
Top Bar Visitor/Patient Counter: In Two Point, total population sits persistently on the lower-right or top HUD chrome as an icon + counter: [Person Silhouette] 42 / 65.
Capacity Warning States:
Normal (< 85%): Neutral off-white text (#E6E6E6).
Near Full (85%–99%): Amber/Yellow text (#F5A623).
At/Over Capacity (100%+): Solid Red (#D0021B) with a subtle pulse animation on the icon.
Room-Level Queues & Limits: When clicking any room (e.g., GP's Office, Ward), the pop-up room card has a dedicated status row: Queue: 6 / 6 (or Beds: 4 / 4). If a patient arrives at a full room, an overhead animated thought-bubble appears above their head: a red room icon with a question mark or exclamation mark.
Notification Ticker / Envelope: When hospital-wide capacity or a room type bottlenecks severely, a circular red warning chip pops onto the right-side notification rail: "Hospital Overcrowded: Build more GP Offices or send patients home."
Visitor Refusal: In Two Point Museum, if museum capacity is hit, arriving visitors stop at the perimeter gate, an exclamation bubble pops above their head, and they turn 180° to walk off-map.
Mad Games Tycoon 2
Room Workplace Counters: Every development room shows capacity directly in its room inspector and overhead tag: Workstations: 4 / 4.
The Overcrowding / Missing Item State: If an employee has no desk or an item lacks space, MGT2 does not rely solely on an overarching top-bar alert. Instead:
The room itself tints slightly red in build/view mode.
An overhead floating warning icon (an empty red desk icon or red silhouette) hovers directly above the worker's head.
The bottom-left room inspector panel explicitly lists the capacity: Staff: 5 | Max Desks: 4 in bright red text (#FF3B30).
Storage / Server Limits: Shown as an explicit bar widget: Server Load: [======    ] 62% or Storage: 18,400 / 20,000. When 100% is reached, the bar turns solid red and flashing text states: Storage Full!.

4. TRAPS & EDGE CASES TO GUARD AGAINST
The "Pre-Locker Room" Trap (Day 1 Minute 0):
The Trap: Showing 0 / 0 on the top bar before the player has drawn a single wall looks like a broken simulation or an error.
The Fix: Until the player draws their first room or completes Goal 4 ("SECURE THE VALUABLES"), the top bar widget shows: [Icon] -- / -- in muted grey (#555555). Hovering says: "Gym closed to public. Complete gym setup to accept members."
The "Phantom Locker" Trap (Locker Placed Outside Locker Room):
The Trap: A player drops a locker bank on the open boxing floor or outside in the grass and expects the member cap to rise.
The Fix: Lockers only register if their footprint resides 100% inside a designated ROOM_TYPE_LOCKER. If placed anywhere else, an amber warning tag sits over the item: NEEDS LOCKER ROOM. Capacity contribution: 0.
The "Instant Eviction" Trap (Deleting a Locker with Active Members):
The Trap: Player has 12 members and deletes the locker bank to get cash back. Do members instantly get fired or disappear?
The Fix: Strict rule: Members already joined never vanish immediately. The display becomes: 12 / 0 in bright pulsing red (#E74C3C). The tooltip displays: CRITICAL DEFICIT: 12 Members using 0 Lockers. Daily churn rate increased to 35% until lockers are restored. Walk-ins halted.
The "Shower Without Drainage/Water" Trap:
If plumbing mechanics exist or showers require wall mounting, prevent players from placing floating shower stalls in the middle of a room that don't hook up. Require back-to-wall snapping.

Exact Capacity Calculation Logic
# res://scripts/economy/MemberCapacityEngine.gd
class_name MemberCapacityEngine
extends RefCounted

const LOCKER_TIER_1_PLACES: int = 12 # Banks 1 to 3
const LOCKER_TIER_2_PLACES: int = 8  # Banks 4 to 6
const LOCKER_MAX_COUNTED_BANKS: int = 6
const SHOWER_STALL_PLACES: int = 15

static func calculate_gym_capacity(locker_banks_in_rooms: int, shower_stalls_in_rooms: int) -> Dictionary:
	var total_locker_places: int = 0
	var counted_banks: int = clampi(locker_banks_in_rooms, 0, LOCKER_MAX_COUNTED_BANKS)

	for i in range(1, counted_banks + 1):
		if i <= 3:
			total_locker_places += LOCKER_TIER_1_PLACES
		else:
			total_locker_places += LOCKER_TIER_2_PLACES

	var total_shower_places: int = shower_stalls_in_rooms * SHOWER_STALL_PLACES
	var final_cap: int = total_locker_places + total_shower_places

	return {
		"total_capacity": final_cap,
		"locker_places": total_locker_places,
		"shower_places": total_shower_places,
		"banks_counted": counted_banks,
		"banks_overflow": maxi(0, locker_banks_in_rooms - LOCKER_MAX_COUNTED_BANKS),
		"next_bank_yield": get_next_bank_yield(counted_banks)
	}

static func get_next_bank_yield(current_counted_banks: int) -> int:
	if current_counted_banks < 3:
		return LOCKER_TIER_1_PLACES
	elif current_counted_banks < LOCKER_MAX_COUNTED_BANKS:
		return LOCKER_TIER_2_PLACES
	return 0
