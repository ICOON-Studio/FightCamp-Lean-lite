1. STRATEGIC VERDICT: DO WE AGREE WITH THE STUDIO HEAD?
The Verdict: YES, AGREE FULLY — WITH TWO STRICT UX SAFEGUARDS.

The studio head's design direction is sharp, production-conscious, and commercially proven. Opening all 6 fully rendered rooms (Reception, Gym Floor/Ring, Manager Office, Physio, Lockers, Equipment Store) in a single unified orthographic overview immediately communicates scope, scale, and high production value.

Rather than hiding unfinished mechanics behind locked doors or artificial "under construction" popups, rendering the props in-engine establishes Anvil Street as a living, breathing club. Restricting interactions to mechanics currently implemented in Godot (starting strictly with the Desk PC in the Office) keeps scope under control while letting the facility speak for itself.

Precedent: How the Genre Handles "Not Yet Live" Objects
Two Point Hospital / Two Point Campus: Every prop, bench, and fire extinguisher is visible from day one. Inactive or unstaffed rooms display an unambiguous world-space floating warning icon (e.g., "Doctor Needed" or "Machine Broken"). Hovering an inactive prop does not display an outline; it returns standard informational tooltip text or remains non-interactive.
Mad Games Tycoon 2: Rooms render fully furnished. Inactive server racks, dev stations, or marketing boards simply do not highlight on hover. Only interactive tools project high-contrast outlines and change the OS cursor to an active pointer.
Punch Club: Non-interactive background props use baked, grounded lighting. Only interactive equipment (bench press, heavy bag, fridge) reacts to cursor mouse-overs with white stencils.

Why Step 2 (16.0 m) MUST Be the Default:
At 36.0 m (Step 1), MetaHuman fighters look small on a 1080p display (the boxer is only ~90 pixels high), making it difficult to read punch snap, hip drive, and footwork.
Step 2 (16.0 m) keeps the fighter centered, readable, and athletic (~210 pixels high), while the office sits clearly visible just off-screen or right at the screen edge.
Toggling between Step 2 and Step 1 is handled instantly via one mouse-wheel tick or by hitting [SPACE] to toggle macro/floor view.
3. HOW THE CLICKABLE DESK PC READS AT THE ZOOMED-OUT OVERVIEW (36.0 m)
At the zoomed-out 36.0 m overview, a 0.48 m monitor renders at approximately 26 x 23 physical pixels on a 1920×1080 display. Relying on clicking those 26 raw screen pixels would be terrible UX. We solve this using a two-layer interaction target.

Click Behavior: Direct UI Open vs Camera Push
The Approved Action: Direct Modal Open with Background Blur.
Clicking the PC from the zoomed-out view must NOT force a slow camera push-in. A camera dive from 36m to desk-level causes unnecessary disorientation if the player just wants to check a purse split or accept a fight contract.
Result of Click: Instantly opens the 2-Tab PC screen (1280×720 centered panel or full-frame overlay) in 0.15s, while applying a gentle radial blur and darkening (Color(0,0,0,0.65)) over the 3D gym background.
Hitting [ESC] or [X CLOSE] dismisses the UI instantly, returning the player to the zoomed-out club overview without moving the camera.

7. GDSCRIPT: TWO-TAB OFFICE PC & FACILITY INTERACTION CONTROLLER
This clean controller manages the two-tab UI, object hover handling, and room camera framing within the 300-line budget.
# FacilityInteractionController.gd
class_name FacilityInteractionController
extends Node3D
signal terminal_opened(initial_tab_index: int)
signal terminal_closed
signal bout_contract_selected(contract_id: String)
signal goal_card_picked(goal_id: String)
enum ZoomStep { MACRO_CLUB = 0, FLOOR_DEFAULT = 1, FOCUS_ROOM = 2 }
@export var camera: Camera3D
@export var terminal_ui_root: Control
@export var office_marker: Marker3D
@export var floor_marker: Marker3D
@export var pc_mesh_outline: GeometryInstance3D
@export var office_billboard_pill: Node3D
# Camera Step Configurations
const ORTHO_SIZES: Array[float] = [36.0, 16.0, 7.0]
var current_step: ZoomStep = ZoomStep.FLOOR_DEFAULT
var target_cam_size: float = 16.0
var target_cam_pos: Vector3
# Live Interactive Objects Registry
var live_objects: Dictionary = {
"OFFICE_PC": { "active": true, "name": "Management Terminal" },
"PHYSIO_TABLE": { "active": false, "name": "Treatment Table" },
"EQUIP_LOCKER": { "active": false, "name": "Gear Storage" },
"FRONT_DESK": { "active": false, "name": "Club Reception" }
}
func _ready() -> void:
assert(camera != null, "Iso Camera reference required.")
camera.projection = Camera3D.PROJECTION_ORTHOGONAL
target_cam_size = ORTHO_SIZES[current_step]
target_cam_pos = floor_marker.global_position if floor_marker else Vector3.ZERO
_update_pill_state(true)
func _process(delta: float) -> void:
# Smooth camera interpolation
camera.size = lerpf(camera.size, target_cam_size, 1.0 - exp(-delta * 10.0))
camera.global_position = camera.global_position.lerp(target_cam_pos, 1.0 - exp(-delta * 10.0))
func set_zoom_level(step: ZoomStep) -> void:
current_step = step
target_cam_size = ORTHO_SIZES[current_step]
func toggle_macro_overview() -> void:
if current_step == ZoomStep.MACRO_CLUB:
set_zoom_level(ZoomStep.FLOOR_DEFAULT)
if floor_marker: target_cam_pos = floor_marker.global_position
else:
set_zoom_level(ZoomStep.MACRO_CLUB)
# --- OBJECT HOVER & CLICK LOGIC ---
func on_prop_mouse_entered(prop_key: String) -> void:
if not live_objects.has(prop_key) or not live_objects[prop_key]["active"]:
return # Inactive prop: do nothing, leave cursor as default arrow
Input.set_default_cursor_shape(Input.CURSOR_POINTING_HAND)
if prop_key == "OFFICE_PC" and pc_mesh_outline:
pc_mesh_outline.set_instance_shader_parameter("outline_enabled", true)
func on_prop_mouse_exited(prop_key: String) -> void:
Input.set_default_cursor_shape(Input.CURSOR_ARROW)
if prop_key == "OFFICE_PC" and pc_mesh_outline:
pc_mesh_outline.set_instance_shader_parameter("outline_enabled", false)
func on_prop_clicked(prop_key: String) -> void:
if not live_objects.has(prop_key) or not live_objects[prop_key]["active"]:
return # Inactive objects ignore click completely
if prop_key == "OFFICE_PC":
open_pc_terminal(0) # Open to Tab 0 (Bout Contracts)
# --- PC TERMINAL (2-TAB ARCHITECTURE) ---
func open_pc_terminal(default_tab: int = 0) -> void:
terminal_ui_root.visible = true
_switch_pc_tab(default_tab)
terminal_opened.emit(default_tab)
func close_pc_terminal() -> void:
terminal_ui_root.visible = false
terminal_closed.emit()
func _switch_pc_tab(tab_index: int) -> void:
# Tab 0: BOUT CONTRACTS (Round 105 Matchmaker List)
# Tab 1: FINANCES (Ledger & Operational Balance)
var tab_bouts: Control = terminal_ui_root.find_child("TabBouts", true, false)
var tab_finances: Control = terminal_ui_root.find_child("TabFinances", true, false)
if tab_bouts and tab_finances:
tab_bouts.visible = (tab_index == 0)
tab_finances.visible = (tab_index == 1)
func _update_pill_state(has_unread_offers: bool) -> void:
if office_billboard_pill:
office_billboard_pill.visible = true
var badge: Control = office_billboard_pill.find_child("AlertBadge", true, false)
if badge: badge.visible = has_unread_offers
