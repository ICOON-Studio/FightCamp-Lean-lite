1. World Labels & Screen-Space Interactive Tags
(a) Architectural Choice: Screen-Space Overlay vs. World-Space Billboard

Two Point Studios titles (Two Point Hospital, Two Point Campus, Two Point Museum) deliberately avoid free-floating 3D text billboards (Label3D) for actionable gameplay entities.

The rationale is clear:

Geometric Scale Invariance: A 3D billboard scaled for floor_close (FOV 17 close framing) becomes either a pinprick or an illegible, overlapping blurry slab when projected back through a 17° telephoto frustum at floor_far (distance ~42m vs ~14m).
Subpixel Aliasing & Font Rendering: FreeType glyph rasterization at runtime directly in 2D viewport space preserves pixel-crisp kerning against our high-contrast UI tokens (#f6eddc on PANEL_GLASS). World-space textured quad quads undergo bilinear downsampling or mip-swapping that turns text muddy under slow isometric camera pans.
Z-Ordering & Draw Order: 2D viewport UI controls live in their own CanvasLayer (layer 10), guaranteeing deterministic z-index layering over 3D geometry without depth-test fighting or requiring transparent depth-write passes.

Decision: The tag system is built entirely in Screen-Space Viewport 2D (CanvasLayer), updated per frame by calculating camera.unproject_position(target_node3d.global_position + Vector3(0, y_offset, 0)).

(c) Visibility, Occlusion & Transition Rules
Always Shown vs. Hover:
Interactive tags are always visible if they possess active, unread notifications (e.g. "2 NEW BOUTS", "CRACKED PIPE").
When no notifications exist:
floor_far: Tags collapse to a compact round 34×34 station pin.
floor_view: Tags show as compact pill labels.
floor_close: Full horizontal tag with status string.
Culling & Distance:
Screen border padding: Tags clamp smoothly or fade out within 32 px of any viewport edge.
Behind Camera: Evaluated via camera.is_position_behind(target_pos). If true, visible = false immediately.
Raycast Occlusion: Optional low-frequency (every 6 frames) sphere-cast from camera to object anchor; if fully occluded by solid partition walls, tag opacity lerps to alpha = 0.2 rather than popping off.

func update_transform_from_camera(cam: Camera3D) -> void:
	if not is_instance_valid(target_node) or not is_instance_valid(cam):
		visible = false
		return

	var world_pos: Vector3 = target_node.global_position + anchor_offset_3d
	if cam.is_position_behind(world_pos):
		visible = false
		return

	var screen_pos: Vector2 = cam.unproject_position(world_pos)
	var viewport_rect: Rect2 = get_viewport_rect()

	# Culling against screen edges with 32px padding
	if not viewport_rect.grow(-32.0).has_point(screen_pos):
		visible = false
		return

	visible = true
	# Center anchor horizontally, sit directly above anchor point vertically
	position = screen_pos - Vector2(size.x * 0.5, size.y)

2. Key Light, Shadows & Modern Gym Aesthetics
Physical Basis & The Long-Shadow Problem

In the user's reference image 2, a single directional light tilted at 52° creates an elongation ratio of:
$$\cot(52^\circ) \approx 0.781$$
A $2.3\text{m}$ high chin-up rig casts a shadow spanning nearly $1.8\text{m}$ across the active play area. Under isometric projection (telephoto FOV 17° with pitch $-35.264^\circ$), horizontal shadows aligned against camera perspective stretch diagonally across navigation corridors, occluding the floor grid and visually obscuring
