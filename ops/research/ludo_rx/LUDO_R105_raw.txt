PART A — THE COACH'S PAD WORK AS A PAIRED CLIP
A1. Pipeline & Tool Decision: Cascadeur Paired Track Import
Selected Pipeline: Cascadeur 2026 (using your local license expiring Oct 27, 2026) alongside your existing Mixamo punch anim as the contact baseline.
Why Mixamo/Web Rigging fails here: Mixamo single clips have no target offset tracking or mitt resistance mechanics. Web automated rigs lack contact physics and solve limbs independently, causing floating or intersecting fists.
Why Cascadeur succeeds: Cascadeur's physical constraint system solves two rigs simultaneously in one project file, guaranteeing hand-to-mitt impact lines, center-of-mass balancing, and reciprocal recoil on the exact contact frames.
Step-by-Step Production Protocol (2.5-hour turnaround)
Scene Setup: Open Cascadeur. Import both MetaHuman skeleton rigs into the same scene. Place the Coach at world origin $(0, 0, 0)$ facing forward along $+Z$. Place Fighter at $(0, 0, 1.15)$ facing $-Z$ (1.15 meters apart, orthodox stance).
Contact Keyframing: Create key poses at frames 0, 24, 42, 66, 96, 126, 156, and 210 based on the timing table in A2. Align the Coach's mitt plane flush to the fighter's fist surface at each impact point.
Physics & Recoil Baking:
Pin Coach hand transforms at impact frame $T$.
On frame $T+2$, apply a 35 mm displacement back along the punch line into the Coach's shoulder and thoracic spine (catch resistance).
Enable Cascadeur's AutoPosing and Spatial Trajectory Smooth on the Coach's arms to produce smooth transitions between pad targets.
Dual Export: Export two separate .glb animations with identical length (240 frames @ 30 fps, looping):
anim_pads_fighter_orthodox_loop.glb
anim_pads_coach_orthodox_loop.glb
Both animations share identical global transform origins $(0,0,0)$, with root motion baked into bone translations so neither actor drifts over multiple loops.

A3. Engine Sync & Spatial Rigging (Godot 4.7.2)

To avoid bone drift, phase misalignment, and asynchronous frame ticks, both rigs must be coordinated by a single controller script.

PadsStation (Node3D) [World Position: e.g. Vector3(-2.4, 0.0, 3.2)]
├── SharedOrigin (Marker3D) [Position: 0, 0, 0]
│   ├── FighterMount (Marker3D) [Position: (0, 0, 0.575), Rotation: 180° Y]
│   │   └── FighterBody (CharacterBody3D -> AnimationPlayer)
│   └── CoachMount (Marker3D) [Position: (0, 0, -0.575), Rotation: 0° Y]
│       └── CoachBody (CharacterBody3D -> AnimationPlayer)
└── PadWorkoutController (Node)

Distance: Exactly $1.15,\text{m}$ between bone root points (root or pelvis_projection).
Facing: Fighter faces forward along local $-Z$ ($180^\circ$ Y-rotation relative to station); Coach faces local $+Z$ ($0^\circ$).
Sync Strategy: Single unified clock. A dedicated node advances playback on both AnimationPlayer nodes using exact frame indices rather than system delta times.
# PadWorkoutController.gd
class_name PadWorkoutController
extends Node

@export var fighter_anim: AnimationPlayer
@export var coach_anim: AnimationPlayer
@export var sync_track_name: String = "pads_routine_orthodox"

func _ready() -> void:
    assert(fighter_anim != null and coach_anim != null, "Animators must be assigned.")
    align_and_lock_actors()

func start_routine(speed_multiplier: float = 1.0) -> void:
    fighter_anim.play(sync_track_name)
    coach_anim.play(sync_track_name)
    fighter_anim.speed_scale = speed_multiplier
    coach_anim.speed_scale = speed_multiplier
    # Hard lock seek position
    fighter_anim.seek(0.0, true)
    coach_anim.seek(0.0, true)

func set_speed(speed_multiplier: float) -> void:
    fighter_anim.speed_scale = speed_multiplier
    coach_anim.speed_scale = speed_multiplier

func snap_sync_check() -> void:
    var diff := absf(fighter_anim.current_animation_position - coach_anim.current_animation_position)
    if diff > 0.016: # Out of sync by more than half a frame @ 30fps
        coach_anim.seek(fighter_anim.current_animation_position, true)

func align_and_lock_actors() -> void:
    var mount_f: Node3D = get_node("../SharedOrigin/FighterMount")
    var mount_c: Node3D = get_node("../SharedOrigin/CoachMount")
    mount_f.position = Vector3(0.0, 0.0, 0.575)
    mount_f.rotation_degrees = Vector3(0.0, 180.0, 0.0)
    mount_c.position = Vector3(0.0, 0.0, -0.575)
    mount_c.rotation_degrees = Vector3(0.0, 0.0, 0.0)

PART D — THE FEELING OF PROGRESSION

To convey improvement without audio or camera angle changes, we rely on kinematic body language and UI telegraphing visible from high broadcast distances.

Ranked Progression Signals (High to Low Value-Per-Engineering-Hour)
Rank 1: Crisp Animation Snap (BlendCurve Tweaks)  [Highest ROI]
Rank 2: Station Target Ring Compaction
Rank 3: Posture Shift Between Workout Blocks
Rank 4: High-Contrast World Floating Numbers
Rank 5: Weekly Silhouette Ghost Overlay           [Lowest ROI]

Detailed Mechanics for Each Progression Indicator
1. Dynamic Snap & Recoil Snappiness (Value Score: 10/10 — Est: 1.5 Hours)
What changes: Blend times between punches decrease as stats rise. At 40 Technique, transitioning from Jab out to Jab chin-return takes 0.16 seconds with a soft linear curve. At 80 Technique, return time is shortened to 0.06 seconds with an aggressive cubic ease-out.
Concrete Values:
Punch return speed scale: lerp(1.0, 1.85, technique / 100.0).
Pad Recoil blend time: 0.18s (Novice) down to 0.05s (Elite).
Broadcast Readability: At wide camera angles, soft punch returns make fighters look amateur and "floaty". Snappy returns look athletic, snappy, and powerful.
2. Station Target Floor Projection Ring (Value Score: 9/10 — Est: 2 Hours)
What changes: A subtle procedural projector ring under the fighter's feet at their current station.
Concrete Values:
Novice (Stat < 50): Ring radius is $1.4,\text{m}$, color is diffuse yellow (#FBBF24 @ 30% alpha), jittering slightly.
Mastered (Stat > 80): Ring tightens down to an exact $0.75,\text{m}$ diameter, stable bright teal (#2DD4BF @ 80% alpha) with crisp, locked edges.
Broadcast Readability: Instantly communicates tighter footwork discipline and balance control at wide camera distances.
3. Idle Fatigue & Posture System (Value Score: 8/10 — Est: 2.5 Hours)
What changes: The fighter's idle posture between rounds and exercise sets directly reflects their Conditioning stat.
Concrete Values:
Low Stamina/Conditioning (<50): Upper torso pitch tilted forward $12^\circ$, hands resting on hips, head hangs down during breaks.
High Conditioning (>75): Upright stance (torso pitch $0^\circ$), active arm bouncing, elbows tucked tight to ribs, chin tucked.
Broadcast Readability: Distinct silhouettes that stand out against the light wooden gym floor.
4. Minimalist World-Space Gain Floaters (Value Score: 7/10 — Est: 1 Hour)
What changes: Small, stylized text popups when a fighter completes a high-quality rep.
Concrete Values: Text rises $0.8,\text{m}$ along $+Y$ and fades out over 1.2 seconds:
Regular rep: +0.2 SPD (Subtle off-white #CBD5E1, 12px font).
Milestones / Personal Bests: ★ MILESTONE: 80 SPEED (Bold Gold #F59E0B, 16px font, rises with slight scale pop).
Broadcast Readability: Contrasts cleanly against the darker station mats and red brick walls.
5. Weekly Ghost Overlay Comparison (Value Score: 6/10 — Est: 4 Hours)
What changes: Pressing a small UI comparison button overlays a translucent wireframe ghost of the fighter's Week 1 self performing the same drill side-by-side.
Concrete Values:
Ghost body: 35% alpha monochrome white wireframe shader (#FFFFFF).
Live body: Full color MetaHuman.
Shows the current fighter completing punch combinations before the ghost even finishes the second strike.
Broadcast Readability: Clearly highlights technical progress and speed differences without needing custom cinematic angles.
PART E — ARCHITECTURAL IMPLEMENTATION (GDSCRIPT)
Core Systems Controller: Bout & Progression Architecture
# FightCampProgressionController.gd
class_name FightCampProgressionController
extends Node

signal goal_settled(outcome_status: String, trust_delta: int, morale_delta: int)
signal bout_booked(opponent_name: String, days_until_fight: int)
signal film_tell_revealed(tell_text: String, bonus_station: String)

enum GoalState { ON_TRACK, AT_RISK, OFF_TRACK, MET, MISSED }

@export var current_trust: int = 50
@export var current_morale: int = 50
@export var active_goal_state: GoalState = GoalState.ON_TRACK

# Booked Opponent Cache
var booked_opponent_id: String = ""
var days_until_fight: int = -1
var active_tell_unlocked: bool = false

# Progression Constants
const TRUST_GAIN_MET: int = 25
const MORALE_GAIN_MET: int = 10
const TRUST_PENALTY_MISSED: int = -25
const MORALE_PENALTY_MISSED: int = -20
const WALKOUT_THRESHOLD: int = 30

func book_bout(athlete_node: Node, offer_id: String, opponent_data: Dictionary) -> void:
    booked_opponent_id = offer_id
    days_until_fight = opponent_data.get("days_out", 14)
    
    # Broadcast floor changes
    bout_booked.emit(opponent_data.get("name", "Unknown Opponent"), days_until_fight)
    _activate_floor_elements_for_fight(opponent_data)

func execute_film_study() -> Dictionary:
    if booked_opponent_id == "":
        return {"success": false, "reason": "No opponent booked"}
    
    active_tell_unlocked = true
    var tell_data := {
        "tell_text": "HABIT: Drops left hand before overhand right.",
        "target_station": "PADS",
        "stat_boost_type": "COUNTER_RIGHT",
        "multiplier": 1.25
    }
    
    film_tell_revealed.emit(tell_data["tell_text"], tell_data["target_station"])
    return {"success": true, "data": tell_data}

func evaluate_day_end_goal(fighter_stat: float, target_stat: float, is_deadline_day: bool) -> void:
    if not is_deadline_day:
        # Mid-camp tracking
        if fighter_stat >= target_stat * 0.9:
            active_goal_state = GoalState.ON_TRACK
        elif fighter_stat >= target_stat * 0.7:
            active_goal_state = GoalState.AT_RISK
        else:
            active_goal_state = GoalState.OFF_TRACK
        return

    # Final Deadline Settlement
    if fighter_stat >= target_stat:
        active_goal_state = GoalState.MET
        current_trust = clampi(current_trust + TRUST_GAIN_MET, 0, 100)
        current_morale = clampi(current_morale + MORALE_GAIN_MET, 0, 100)
        goal_settled.emit("MET", TRUST_GAIN_MET, MORALE_GAIN_MET)
    else:
        active_goal_state = GoalState.MISSED
        current_trust = clampi(current_trust + TRUST_PENALTY_MISSED, 0, 100)
        current_morale = clampi(current_morale + MORALE_PENALTY_MISSED, 0, 100)
        goal_settled.emit("MISSED", TRUST_PENALTY_MISSED, MORALE_PENALTY_MISSED)
        
        if current_trust < WALKOUT_THRESHOLD:
            _trigger_walkout_warning()

func calculate_animation_snap(speed_stat: float, tech_stat: float) -> Dictionary:
    var avg_stat: float = clampf((speed_stat + tech_stat) * 0.5, 0.0, 100.0)
    var speed_scale: float = lerpf(0.85, 1.30, avg_stat / 100.0)
    var blend_time: float = lerpf(0.18, 0.05, avg_stat / 100.0)
    var miss_offset_mm: float = lerpf(45.0, 0.0, avg_stat / 100.0)
    
    return {
        "speed_scale": speed_scale,
        "blend_time": blend_time,
        "miss_offset_mm": miss_offset_mm
    }

func _activate_floor_elements_for_fight(data: Dictionary) -> void:
    # 1. Update Gameplan Readiness light hooks
    var tv_mesh: Node3D = Engine.get_main_loop().root.find_child("FilmTVNode", true, false)
    if is_instance_valid(tv_mesh) and tv_mesh.has_method("set_screen_active"):
        tv_mesh.set_screen_active(true, data.get("name", "Target"))

func _trigger_walkout_warning() -> void:
    push_warning("Fighter trust below safe threshold. Walkout risk active.")
