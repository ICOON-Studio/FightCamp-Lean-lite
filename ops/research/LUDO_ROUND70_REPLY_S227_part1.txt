
FIGHTCAMP (S227) — ROUND 70: UIBIBLE1
THE UNIFIED DESIGN SYSTEM & UI BIBLE FOR THE WHOLE GAME

Document Reference: FC-SPEC-S227-UIBIBLE1-DESIGN-SYSTEM

Target Engine: Godot 4.7.2 Forward+, pure GDScript controls, native $1920 \times 1080$, dynamic graceful scaling down to $1280 \times 720$.

Core Theme Directive: Gleason’s Gym 1970s Industrial Dossier (Aged Brass, Championship Gold, Deep Charcoal, Stamped Steel, Oxblood, Bond Paper Cream). No neon greens, no blue lasers, no pure white blinding text, no raw unbordered grey boxes.

Every screen violates visual cohesion across five core dimensions:

1. Inconsistent Gold/Yellow Palette (6 Different Hues across 6 Screens)
Screen A (Globe): Uses an antique ochre brass (#d4af37 / #c89e3a) for borders and header bands.
Screen B (Gym Floor HUD): Uses a vibrant, oversaturated "construction mustard" (#f5b82e) on the top date chip and bottom-right "GUIDE" button.
Screen C (Training Planner): Introduces a dull light mustard on "WATCH THE FLOOR" (#e8b338) while retaining the bright yellow "GUIDE" button at the bottom right.
Screen D (Profile Overview): Shifts entirely to an electric amber/orange (#ff9f1c) for the "UNASSIGNED" button and stat meters.
Screen E (Profile Career): Ditches yellow entirely, substituting a bright neon arcade green (#00ff7f) and electric indigo (#5865f2).
Screen F (Quick-Look): Uses a desaturated muted bronze on the top buttons with pale yellow text labels.
2. Panel Materiality and Depth Fractures
Screen A: Features physical inset cards with $1.5\text{ px}$ brass trims and dark leatherette fills.
Screen B & F: Floor HUD and Quick-Look Card use floating translucent glassmorphism (rgba(24, 26, 30, 0.85)) with rounded corners that clash with the period aesthetic.
Screen C: Renders flat, borderless CSS-style grey rectangles floating in an unlit void.
Screen D & E: Dark slate blue cards (#1b2028) with razor-sharp borders and zero tactile framing, completely abandoning the Gleason gym theme.
3. Button Geometry, Weights, and Hover States
Screen A: Stamped full-width rectangular brass block ("CHOOSE MARKET").
Screen B: Oval, heavily rounded pill buttons ("Mon 5 Feb", "Guide - Hire a coach").
Screen C: Squircle preset buttons, pill drag items, and sharp-cornered day cells.
Screen D: Rectangular flat orange block button with dark text.
Screen E: Rounded sci-fi neon green ("EXTEND CONTRACT") and blue buttons ("RENEGOTIATE CONTRACT").
Screen F: Deep recessed dark buttons with microscopic borders.
4. Typography Anarchy
Multiple font families collide: Inter/Roboto clean sans-serif (Screens B, C, F), monospaced terminal code (Screen E), and condensed Gothic display titles (Screen A, C).
Inconsistent font cases: Some screens use UPPERCASE with tracking (Screen A), others use Title Case (Screen B), and some mix lowercase and uppercase haphazardly (Screen D, E).
Text brightness varies wildly: Screen E uses raw #ffffff that blows out contrast, while Screen C uses muted #777777 that is unreadable at $1080\text{ p}$.
5. UI Canvas Integration
The top HUD bar and left icon rail look like an engine debug overlay stuck onto the viewport, completely disconnected from the screens below them.

3. SPACING GRID & CORNER RADII

All UI layout follows a strict $4\text{ px}$ base unit with an $8\text{ px}$ structural grid:

Micro Spacing: $SP_2 = 2\text{ px}$ (Divider offsets, borders)
Tight Spacing: $SP_4 = 4\text{ px}$ (Segment gap, badge internal padding)
Standard Component Gap: $SP_8 = 8\text{ px}$ (Table row gap, button item spacing)
Container Padding: $SP_12 = 12\text{ px}$ (Card inner margins, chip padding)
Block Separation: $SP_16 = 16\text{ px}$ (Distance between header and content)
Major Grid Gaps: $SP_24 = 24\text{ px}$ (Column gutter between primary dockets)
Screen Margin Buffer: $SP_40 = 40\text{ px}$ (Canvas perimeter padding)
Corner Radii (No hyper-rounded modern iOS pills):
RADIUS_NONE: $0\text{ px}$ (Sharp corners for table headers, divider strips, progress fills).
RADIUS_PILL: $2\text{ px}$ (Meters, micro badges, tags, indicator dots).
RADIUS_CARD: $3\text{ px}$ (Attribute tiles, day cells, focus drag blocks).
RADIUS_PANEL: $4\text{ px}$ (Major screens, modals, session drawer, roster cards).
