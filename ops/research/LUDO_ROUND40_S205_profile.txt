A.2 Node Display States & Visual Rules

Each technique node within the branch list is displayed as an ultra-crisp, high-density chip ($w=644\text{ px}$, $h=58\text{ px}$). Its state determines its borders, backgrounds, and interactive readouts:

+----------------------------------------------------------------------------------------------------+
| [T2] LEAD HOOK                   MASTERY: [||||||||||||||||||||] 78% (PROFICIENT) | DRILL: BAG 2   |
| Req: Jab T1, Cross T1 | Tech: 34, Pwr: 38               Speed: 10.8 m/s | Stm: 5.2 | Quota: 4.0h/w |
+----------------------------------------------------------------------------------------------------+

The 5 Concrete Display States

LOCKED (Requirements Unmet):

Visual Styling: Border $1\text{ px}$ #1E293B, background #0A0D14, text #475569.
Content: Node Name, Tier Badge ([T2]), precise missing prereqs shown in red #EF4444 (e.g., MISSING: Rear Cross T1 (Mastery 0%), Technique 34 (Current: 28)).
Interaction: Unclickable for animation preview; clicking opens dependency pathing tooltip.

AVAILABLE (Trainable / Unlocked, 0% Mastery):

Visual Styling: Border $1\text{ px}$ #334155, background #0F172A, text #94A3B8.
Content: Node Name, Tier Badge, MASTERY: 0% [UNLEARNED], required attributes met in muted grey.
Interaction: Clickable; stages base unrefined preview if certified; button [ASSIGN TO TRAINING PLAN] enabled.

LEARNING (Actively Assigned to Gym Station):

Visual Styling: Border $1\text{ px}$ vibrant green #22C55E, background #0B1F17, text #F8FAFC.
Content: Node Name, current mastery percentage with animated progress fill, and explicit assignment tag: LEARNING AT: HEAVY BAG 2 (4.0 h/wk) -> +1.4%/wk.
Interaction: Full 3D stage clip execution; telemetry reflects current partial mastery metrics.

MASTERED (Proficient / Bout-Ready, Mastery $\ge 70%$):

Visual Styling: Border $1\text{ px}$ gold #D69E2E, background #1C1917, text #FACC15.
Content: Node Name, Tier Badge, MASTERY: 94% [CERTIFIED], Gameplan Weight pill ([PRIMARY] / [SITUATIONAL]).
Interaction: Full 3D stage preview with peak execution velocity and crisp recovery frames.

NOT-IN-THIS-BUILD (Uncertified Mechanics for Demo):

Visual Styling: Border $1\text{ px}$ dashed #334155, background #07090E, text #64748B.
Content: Node Name, Tier Badge, tag: SIMULATION ACTIVE | NO 3D ANIMATION CLIP IN DEMO.
Interaction: Trainable in numbers and fully calculated in the fight engine, but the 3D Stage renders a static biomechanical guard pose with a clean telemetry label: [3D PREVIEW UNAVAILABLE FOR THIS NODE].

C.1 Centre Panel Empty State: "Fighter at Rest"
The Problem

When the player has not clicked a specific technique, an unconfigured screen often leaves the 3D viewport blank or displays a broken T-pose.

The FightCamp Implementation
The 3D Scene Remains Live:
The athlete stands centered on the circular gym-mat plinth in their natural stance (ORTHODOX or SOUTHPAW).
Plays a smooth, low-energy idle breathing loop (box_guard_idle).
The camera frames the fighter in the standard Front-Three-Quarter view ($2.40\text{ m}$ distance, $34^\circ$ FOV).
The Sub-Stage Telemetry Card:
Text reads: BASE STANCE: ORTHODOX GUARD | IDLE TELEMETRY (in clean slate #94A3B8).
Metrics read: REACH EXTENSION: 73.5 INCHES | CENTER OF MASS: BALANCED (50/50 SPLIT).
Buttons: [ORBIT VIEW] active, [SLOW-MO] disabled (greyed out), [PLAY/PAUSE] pauses the breathing loop.
Tooltip: "Select any technique node from the right-hand repertoire tree to preview biomechanical execution, frame data, and stamina drain."
