PART A: THE 6 DEAD MOMENTS ON THE GYM FLOOR

Running the 10-minute floor loop with Rounds 79–83 active (station queues, floating stat gains, gold dots, coach boost, wrap drawers) reveals clear dead zones. The simulation has math, but lacks instant tactical feedback, organic friction, and tactile player input.

1. The Empty Reps Deadlock (No Instant Tactical Grip)
The Moment: Fighter is on Heavy Bag 2 for 45 game-minutes. The floating +1.4 POWER pop-up appears at 15-minute intervals, but the player is purely passive. There is zero tactical leverage over how the fighter hits the station during that block.
Smallest Fix (Fix #1): "Corner Urge / Form Cue" (Quick Pointers). Every 15 minutes or upon click, give 3 tactile tactical cues on his active card: Power Through (+25% stat gain, -20% stamina burn), Crisp Form (+40% technique/card mastery rate, standard stamina), or Pace Yourself (-30% stamina burn, small chin/guard recovery). Clicking one fires an immediate visual reaction, modifies the tick rate for the remaining station slice, and creates direct agency without entering deep submenus.
2. Sparring Sparsity & Partner Idle Ghosting
The Moment: When sending the fighter to the ring, Sal "The Anvil" Barone merely acts as a stat coefficient multiplier. There is no tangible visual or textual simulation of a sparring clash, slipping a hook, or getting caught clean in the ring until the end-of-day summary.
Smallest Fix (Fix #2): "Sparring Spar-Event Pulse & Stash". While in the ring, every 10–20 in-game minutes triggers an autonomous micro-event pulse: Clash / Slip / Caught Clean / Counter. Displays a floating combat beat (e.g., "SLIPPED LEAD JAB -> +0.8 FIGHT IQ" or "CAUGHT CLEAN: CHIN 79"), logs a tell progress tick (+3% against Perez/Meat-Axe style), and tests composure drift live on the floor.
3. Move Card Mastery Ghosting (The 120-min & 600-min Dead Stretch)
The Moment: The player assigned 3 move cards (e.g., Slip Outside -> Right Cross). The fighter drills on Slip Rope or Pads, but the progression toward 120 drilled minutes (usable) and 600 minutes (mastered pad chain) feels like an invisible black box until the final unlock occurs.
Smallest Fix (Fix #3): "Pad Chain Mastery Milestone Breakouts". Fire a distinctive floating UI fanfare and floor banner the exact minute a move card crosses 25%, 50%, 75%, usable (120m), or mastered (600m). Provides immediate operational feedback: "TECH DRILL UNLOCKED: SLIP OUTSIDE (USABLE IN FIGHT)" with temporary stat momentum.
4. Co-Trainee / Member Background Deadness
The Moment: 3 paying gym members and sparring partners train in the background zones to generate dues, but feel like sterile background props. They do not interact with the atmosphere or create organic gym friction.
Smallest Fix (Fix #4): "Floor Vibe & Member Spark". Ambient micro-praise or disruptions: paying members react when the head coach coaches a station ("Look at the snap on that cross"), boosting gym prestige points (+1 Prestige) or occasionally crowding a station, forcing station switching or quick coaching decisions.
5. Shift Fatigue & Sudden "Exhausted" Brick Wall
The Moment: Stamina drops smoothly, but at 24 stamina the fighter abruptly drops to EXHAUSTED state with an amber warning. The transition lacks physical ramp-up; the player is caught off-guard if distracted by office menus.
Smallest Fix (Fix #5): "Breathing & Form Degradation Warning Bands". Three distinct threshold shifts: Winded (stamina 45–35, posture drops, pace slows -10%), Heavy Legs (34–25, missed reps, chance of slight tweak), Gasping/Exhausted (<25). Audible gasp / sweat tick and subtle visual floor indicator warn the player 2 game-hours before burnout occurs.
6. Office-to-Floor Disconnect (Visiting Coach & Staff Idle)
The Moment: Hiring an assistant or having a visiting coach feels locked to passive percentage boosts. You don't feel their physical presence on the floor zones.
Smallest Fix (Fix #6): "Assistant Shadow Assignment". Assistant coach physically pins to an aisle or secondary station zone with a visible clip marker: "ASST: RUNNING BAGS (80%)". Clicking the assistant gives an instant 1-second audit toast of who is slacking or off-weight.

const CUE_POWER_THROUGH: String = "power_through"
const CUE_CRISP_FORM: String = "crisp_form"
const CUE_PACE_YOURSELF: String = "pace_yourself"

static func get_cue_definition(cue_id: String) -> Dictionary:
	match cue_id:
		CUE_POWER_THROUGH:
			return {
				"id": CUE_POWER_THROUGH,
				"label": "POWER THROUGH",
				"stat_multiplier": 1.30,
				"stamina_cost_multiplier": 1.25,
				"technique_gain_bonus": 0.0,
				"composure_delta": 2,
				"description": "+30% Raw Stat Gains, +25% Stamina Burn."
			}
		CUE_CRISP_FORM:
			return {
				"id": CUE_CRISP_FORM,
				"label": "CRISP FORM",
				"stat_multiplier": 1.0,
				"stamina_cost_multiplier": 1.0,
				"technique_gain_bonus": 0.35, # Extra mastery minutes per minute
				"composure_delta": 4,
				"description": "Standard Burn, +35% Pad Chain Mastery & IQ."
			}
		CUE_PACE_YOURSELF:
			return {
				"id": CUE_PACE_YOURSELF,
				"label": "PACE YOURSELF",
				"stat_multiplier": 0.75,
				"stamina_cost_multiplier": 0.60,
				"technique_gain_bonus": 0.0,
				"composure_delta": 1,
				"description": "-40% Stamina Drain, Conserves Tank."
			}
		_:
			return {
				"id": "none",
				"label": "NORMAL",
				"stat_multiplier": 1.0,
				"stamina_cost_multiplier": 1.0,
				"technique_gain_bonus": 0.0,
				"composure_delta": 0,
				"description": "Standard work rate."
			}

static func apply_cue_to_tick(fighter_state: Dictionary, cue_id: String, base_stat_gain: float, base_stamina_cost: float, minutes: int) -> Dictionary:
	var def: Dictionary = get_cue_definition(cue_id)
	var final_stat_gain: float = (base_stat_gain * float(def["stat_multiplier"]))
	var final_stamina_drain: float = (base_stamina_cost * float(def["stamina_cost_multiplier"]))
	var bonus_mastery_minutes: float = (float(minutes) * float(def["technique_gain_bonus"]))
	
	var current_stamina: float = float(fighter_state.get("stamina", 100.0))
	var current_composure: int = int(fighter_state.get("composure", 50))
	
	current_stamina = clampf(current_stamina - final_stamina_drain, 0.0, 100.0)
	current_composure = clampi(current_composure + int(def["composure_delta"]), 0, 100)
	
	return {
		"stat_gain": final_stat_gain,
		"stamina_cost": final_stamina_drain,
		"remaining_stamina": current_stamina,
		"composure": current_composure,
		"bonus_mastery_minutes": bonus_mastery_minutes,
		"cue_used": cue_id
	}

class_name GymSparringPulseRules
extends RefCounted

const BEAT_SLIP_COUNTER: String = "slip_counter"
const BEAT_CAUGHT_CLEAN: String = "caught_clean"
const BEAT_CLINCH_BREAK: String = "clinch_break"
const BEAT_TELL_SPOTTED: String = "tell_spotted"

static func roll_sparring_beat(fighter_stats: Dictionary, partner_stats: Dictionary, rand_val: float) -> Dictionary:
	var f_defense: float = float(fighter_stats.get("defense", 45.0))
	var f_iq: float = float(fighter_stats.get("fight_iq", 50.0))
	var p_power: float = float(partner_stats.get("power", 50.0))
	
	# IQ and defense weight the outcome
	var slip_threshold: float = 0.35 + (f_iq * 0.003) + (f_defense * 0.002) # ~0.60
	var clean_threshold: float = slip_threshold + (0.28 - (f_defense * 0.0015)) # ~0.82
	
	if rand_val <= slip_threshold:
		return {
			"beat": BEAT_SLIP_COUNTER,
			"banner_text": "SLIPPED JAB -> CRISP COUNTER",
			"iq_gain": 0.45,
			"composure_delta": 3,
			"chin_wear": 0.0,
			"tell_progress": 0.04,
			"accent_color": "#f0c233" # Gold
		}
	elif rand_val <= clean_threshold:
		var chin_loss: float = 0.15 + (p_power * 0.002)
		return {
			"beat": BEAT_CAUGHT_CLEAN,
			"banner_text": "CAUGHT WITH RIGHT HOOK",
			"iq_gain": 0.1,
			"composure_delta": -4,
			"chin_wear": chin_loss,
			"tell_progress": 0.01,
			"accent_color": "#d94336" # Red
		}
	else:
		return {
			"beat": BEAT_TELL_SPOTTED,
			"banner_text": "TELL READ: OPPONENT DROPS GUARD",
			"iq_gain": 0.60,
			"composure_delta": 5,
			"chin_wear": 0.0,
			"tell_progress": 0.10,
			"accent_color": "#5bc266" # Green
		}

static func apply_sparring_tick(fighter_state: Dictionary, beat_result: Dictionary) -> Dictionary:
	var updated: Dictionary = fighter_state.duplicate()
	var iq: float = float(updated.get("fight_iq", 50.0)) + float(beat_result.get("iq_gain", 0.0))
	var comp: int = clampi(int(updated.get("composure", 50)) + int(beat_result.get("composure_delta", 0)), 10, 100)
	var chin: float = clampf(float(updated.get("chin", 80.0)) - float(beat_result.get("chin_wear", 0.0)), 10.0, 100.0)
	var tell_acc: float = clampf(float(updated.get("tell_progress", 0.0)) + float(beat_result.get("tell_progress", 0.0)), 0.0, 1.0)
	
	updated["fight_iq"] = iq
	updated["composure"] = comp
	updated["chin"] = chin
	updated["tell_progress"] = tell_acc
	return updated

class_name GymMasteryRules
extends RefCounted

const USABLE_MINUTES: int = 120
const MASTERED_MINUTES: int = 600

# Tracks and returns unlocked tier if crossed this exact tick
static func tick_card_drilling(current_drilled_minutes: int, additional_minutes: int) -> Dictionary:
	var start_mins: int = current_drilled_minutes
	var end_mins: int = current_drilled_minutes + additional_minutes
	
	var crossed_25: bool = (start_mins < 30 and end_mins >= 30)
	var crossed_usable: bool = (start_mins < USABLE_MINUTES and end_mins >= USABLE_MINUTES)
	var crossed_half: bool = (start_mins < 300 and end_mins >= 300)
	var crossed_mastered: bool = (start_mins < MASTERED_MINUTES and end_mins >= MASTERED_MINUTES)
	
	var milestone_tier: String = ""
	var toast_message: String = ""
	
	if crossed_mastered:
		milestone_tier = "MASTERED"
		toast_message = "MOVE CARD FULLY MASTERED (PAD CHAIN ACTIVE)"
	elif crossed_usable:
		milestone_tier = "USABLE"
		toast_message = "MOVE CARD DRILL COMPLETE: USABLE IN BOUTS"
	elif crossed_half:
		milestone_tier = "HALFWAY"
		toast_message = "MOVE CARD AT 50% MASTERY"
	elif crossed_25:
		milestone_tier = "STARTED"
		toast_message = "TECHNIQUE GROOVED: 25% MASTERY"
		
	return {
		"new_drilled_minutes": end_mins,
		"milestone_crossed": milestone_tier != "",
		"milestone_tier": milestone_tier,
		"toast_message": toast_message,
		"is_usable": end_mins >= USABLE_MINUTES,
		"is_mastered": end_mins >= MASTERED_MINUTES
	}

static func calculate_chain_fire_chance(card_mastery_mins: int, fight_iq: float) -> float:
	var pct: float = clampf(float(card_mastery_mins) / float(MASTERED_MINUTES), 0.0, 1.0)
	if pct < 0.25:
		return 0.0
	# GDD Formula: chance = mastery * ring IQ / 70
	var chance: float = (pct * fight_iq) / 70.0
	return clampf(chance, 0.0, 1.0)
