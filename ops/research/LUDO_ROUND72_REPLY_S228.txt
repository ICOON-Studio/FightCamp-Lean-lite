Project: FightCamp (PC Native Simulation / Steam Tactical Sports RPG)

Resolution Standard: 1920 × 1080 (16:9 fixed canvas viewport)

Binding Visual Language: Round-70 UI Bible (Foundry Void #0d0c0b, Layered Warm Slates #1a1816 / #22201d / #282521, Brass Filigree borders #3d352a / #5a4d3b, Championship Gold #f0c233, Parchment/Cream text hierarchy #f5ebd9 / #d4c8b8 / #8a7f72, corner radius 4px, 36px standard tab height with 2px active Gold bottom accent).

SECTION A: DEFECT AUDIT OF ATTACHED SCREENSHOTS
Screen 1: THE STORY INBOX ("Dessa's call")
Dead Horizontal Gutter / Cavernous Void: The single story message card stretches arbitrarily across the middle (w ≈ 1120px, h ≈ 168px) floating in vast empty space. 70% of the active viewport is dead amber-black gradient with no dual-pane master-detail structure, no message thread list, no sender visual portrait, and no contextual narrative card docket.
Missing Master/Detail Split Architecture: Standard tactical management games (Football Manager, Suzerain) require a left-hand navigation list (sender avatar, date/stamp, status, urgency tag, brief excerpt) and a right-hand reading reading pane / dossier viewer. Here, the reader is stuck with an unanchored isolated bubble.
No Visual Identity / Character Presence: Dessa is introduced strictly through a tiny flat muted yellow tag "DESSA" and plain text. In a narrative boxing management game centered on inheriting an atmospheric gym, there is no portrait frame, no stamp, no typewriter/telex texture, no sender stamp, and zero tactile identity.
CTA Styling Disconnection: The button "Open the gym" is rendered as an oversized rounded pill (border-radius > 12px) filled with flat warm yellow and black bold text. This contradicts the Round-70 UI Bible spec: 4px corner radius, Championship Gold #f0c233 hover state, 1px brass outline, sharp crisp bevel, and clear consequence metadata indicator (e.g., + Gym Unlocked, Time Advances to 08:00).
No Decision Stakes / Consequence Preview: Narrative choices in FightCamp alter boxer morale, cash flow, gym heat, or relations. The current action gives zero indication of system impact or outcome preview.
Top Header & Tab Bar Desynchronization: "THE INBOX" header has loose breadcrumb text (1 WAITING · CHAPTER 1 · KEYS) floating under it without clear typography scale, and the top-right button "THE WALL" sits adrift without belonging to a standardized 36px segmented navigation tab or view-switcher control.
Under-designed Breadcrumb / Back Navigation: The ← arrow button at the top-left sits isolated without proper hover padding or keybinding indicator ([ESC] / [B]).
Screen 2: THE STORY WALL (Chapter Progression Grid)
Dull, Repetitive Grid Fatigue: Nine uniform cards arranged in a 4-column, 3-row grid with low visual hierarchy. Every card shares an identical muddy gray-brown gradient pill shape, identical muted border, and low-contrast typography. It feels like an uninspired placeholder debug menu rather than a tactile "Gym Wall of Fame / History Pegboard."
Generic "???" Card Clutter: Cards 2 through 9 are slapped with large raw "???" labels, and 6 of them show premature micro-spoilers in low-contrast locked subtext ("CHOOSE THE KID'S FIRST FOCUS", "RENT IS DUE IN FOUR WEEKS"). Locked state taxonomy is inverted: locked narrative beats should either show atmospheric thematic silhouettes, locked padlock/seal icons, or gym pin-board sketches, not raw developer strings.
Absence of Narrative Lineage / Visual Connectors: A story wall must chart a journey (Acts / Chapters / Milestones). The current grid displays no connecting linework, progression cords, act dividers, milestone trophies, or chronology flow.
Dead Area at Bottom Left: The label "YOUR FIGHTERS: NOBODY YET" is parked at the bottom left with zero visual housing, missing polaroid slots, fighter roster pins, or unlocked newspaper clippings.
Lack of State Contrast: Completed/current card ("DESSA'S CALL") looks nearly indistinguishable from locked cards except for the white text versus gray text. There is no brass framing, no Championship Gold highlight, no visual stamp (e.g., RESOLVED, ACTIVE OBJECTIVE), and no polaroid thumbnail photo.

1. InboxMessageCard.gd
class_name InboxMessageCard
extends PanelContainer

signal message_selected(message_id: String)

@export var color_void: Color = Color("#0d0c0b")
@export var color_panel_normal: Color = Color("#22201d")
@export var color_panel_hover: Color = Color("#282521")
@export var color_border_normal: Color = Color("#3d352a")
@export var color_border_selected: Color = Color("#f0c233")
@export var color_unread_gold: Color = Color("#f0c233")

@onready var unread_indicator: ColorRect = %UnreadIndicator
@onready var label_sender: Label = %LabelSender
@onready var label_date: Label = %LabelDate
@onready var label_preview: Label = %LabelPreview
@onready var border_rect: ReferenceRect = %BorderRect

var current_msg_id: String = ""
var is_unread: bool = true
var is_active: bool = false

func _ready() -> void:
	custom_minimum_size = Vector2(504, 88)
	mouse_entered.connect(_on_mouse_enter)
	mouse_exited.connect(_on_mouse_exit)
	gui_input.connect(_on_gui_input)
	_apply_style(color_panel_normal, color_border_normal)

func setup(data: Dictionary) -> void:
	current_msg_id = data.get("id", "")
	label_sender.text = data.get("sender_name", "UNKNOWN").to_upper()
	label_date.text = data.get("date_str", "W1 MON")
	label_preview.text = data.get("preview_text", "")
	is_unread = data.get("unread", true)
	unread_indicator.color = color_unread_gold if is_unread else color_border_normal

func set_selected(selected: bool) -> void:
	is_active = selected
	var border = color_border_selected if is_active else color_border_normal
	var bg = color_panel_hover if is_active else color_panel_normal
	_apply_style(bg, border)

func _apply_style(bg_col: Color, border_col: Color) -> void:
	var style: StyleBoxFlat = StyleBoxFlat.new()
	style.bg_color = bg_col
	style.set_corner_radius_all(4)
	style.border_color = border_col
	style.set_border_width_all(1)
	add_theme_stylebox_override("panel", style)

func _on_mouse_enter() -> void:
	if not is_active:
		var tween = create_tween().set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_OUT)
		tween.tween_property(self, "position:y", position.y - 2.0, 0.12)
		_apply_style(color_panel_hover, color_border_selected)

func _on_mouse_exit() -> void:
	if not is_active:
		var tween = create_tween().set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_OUT)
		tween.tween_property(self, "position:y", position.y + 2.0, 0.12)
		_apply_style(color_panel_normal, color_border_normal)

func _on_gui_input(event: InputEvent) -> void:
	if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
		message_selected.emit(current_msg_id)

2. StoryWallCard.gd
class_name StoryWallCard
extends PanelContainer

signal open_inbox_requested(msg_id: String)
signal inspect_chapter_requested(chapter_id: String)

enum CardState { LOCKED, ACTIVE, COMPLETED }

@export var color_bg_locked: Color = Color("#171513")
@export var color_bg_active: Color = Color("#22201d")
@export var color_bg_completed: Color = Color("#1a1816")
@export var color_gold: Color = Color("#f0c233")
@export var color_brass: Color = Color("#5a4d3b")
@export var color_border_dim: Color = Color("#282521")

@onready var chapter_tag: Label = %ChapterTag
@onready var title_label: Label = %TitleLabel
@onready var requirement_label: Label = %RequirementLabel
@onready var status_badge: Label = %StatusBadge
@onready var thumbnail_rect: TextureRect = %ThumbnailRect
@onready var action_button: Button = %ActionButton

var current_state: CardState = CardState.LOCKED
var chapter_id: String = ""
var linked_msg_id: String = ""

func _ready() -> void:
	custom_minimum_size = Vector2(360, 220)
	action_button.pressed.connect(_on_action_pressed)

func setup_card(data: Dictionary) -> void:
	chapter_id = data.get("chapter_id", "")
	linked_msg_id = data.get("linked_msg_id", "")
	current_state = data.get("state", CardState.LOCKED)
	
	match current_state:
		CardState.LOCKED:
			_render_locked(data)
		CardState.ACTIVE:
			_render_active(data)
		CardState.COMPLETED:
			_render_completed(data)

func _render_locked(data: Dictionary) -> void:
	chapter_tag.text = data.get("roman_numeral", "CH. ??")
	title_label.text = "LOCKED MILESTONE"
	title_label.modulate = Color("#5a4d3b")
	requirement_label.text = "UNLOCK: " + data.get("unlock_condition", "Progress current arc")
	requirement_label.visible = true
	thumbnail_rect.modulate = Color(0.2, 0.2, 0.2, 0.5)
	status_badge.visible = false
	action_button.visible = false
	_set_box_style(color_bg_locked, color_border_dim, 1)

func _render_active(data: Dictionary) -> void:
	chapter_tag.text = data.get("roman_numeral", "CHAPTER I")
	title_label.text = data.get("title", "DESSA'S CALL")
	title_label.modulate = Color("#f5ebd9")
	requirement_label.visible = false
	thumbnail_rect.texture = data.get("thumbnail_texture", null)
	thumbnail_rect.modulate = Color.WHITE
	status_badge.text = "ACTIVE IN INBOX"
	status_badge.visible = true
	action_button.text = "VIEW MESSAGE"
	action_button.visible = true
	_set_box_style(color_bg_active, color_gold, 2)
	_start_pulse_glow()

func _render_completed(data: Dictionary) -> void:
	chapter_tag.text = data.get("roman_numeral", "CHAPTER I")
	title_label.text = data.get("title", "DESSA'S CALL")
	title_label.modulate = Color("#d4c8b8")
	requirement_label.text = "RESOLVED: " + data.get("completion_date", "Week 1 Mon")
	requirement_label.visible = true
	thumbnail_rect.texture = data.get("thumbnail_texture", null)
	thumbnail_rect.modulate = Color(0.8, 0.8, 0.8, 0.9)
	status_badge.text = "ARCHIVED"
	status_badge.visible = true
	action_button.text = "INSPECT LOG"
	action_button.visible = true
	_set_box_style(color_bg_completed, color_brass, 1)

func _set_box_style(bg: Color, border: Color, width: int) -> void:
	var style = StyleBoxFlat.new()
	style.bg_color = bg
	style.border_color = border
	style.set_border_width_all(width)
	style.set_corner_radius_all(4)
	add_theme_stylebox_override("panel", style)

func _start_pulse_glow() -> void:
	var tween = create_tween().set_loops().set_trans(Tween.TRANS_SINE)
	tween.tween_property(self, "theme_override_styles/panel:border_color", Color("#ffe58f"), 0.8)
	tween.tween_property(self, "theme_override_styles/panel:border_color", color_gold, 0.8)

func _on_action_pressed() -> void:
	if current_state == CardState.ACTIVE:
		open_inbox_requested.emit(linked_msg_id)
	elif current_state == CardState.COMPLETED:
		inspect_chapter_requested.emit(chapter_id)
