# STYLE4 - three named styles do nothing in a bout: give each a lever the fight reads every round (Kalli, design)

Read first: ops/research/CRITIC_PACK.md (the game). Source: ops/research/PROGRESSION_MAP_S448.md section 10 (the six named
styles, table lines 144-150) and docs/STYLE3_RESULT.md (Goose's measured lever table, S484).

## The measured problem (20 fighters x 20 bouts a cell, 4 opponent styles)
| Style | Lever today | Reads | Applied | Worth (wins in 100) |
|---|---|---|---|---|
| Out-boxer | range_open +0.1 (steers to long range every exchange) | 720 | 720 | 0.8 |
| Volume puncher | combo_energy x0.9 (combos cost less) | 60 | 60 | 2.75 |
| Pressure fighter | pressure_answers x1.2 | 720 | 720 | 1.0 |
| Boxer-puncher | plan edge at mid range +0.1, only when the planned line already has an edge | 240 | 120 | 0.0 |
| Counter-puncher | counter lines' edge +0.15 when the opponent loads up or presses, same condition | 140 | 60 | 0.0 |
| Slugger | knockdown chance x1.1 (Knockdowns: ~2 counts in 100 bouts) | 8 | 1 | 0.25 |
Target: each style worth 1.5-4 wins in 100, and no style best against all four opponents (Volume puncher is today).
Doubling the three bottom numbers moved nothing: their conditions are rarely true, so the lever is the problem, not the number.

## Ask
1. For Boxer-puncher, Counter-puncher and Slugger, propose ONE new lever each that a bout reads in most exchanges, true to
   the style's picture in the map ("holds the middle, steps in behind the cross"; "held stance, steps back and returns";
   "rolls under, plants to hook"). Name what the fight already has that it would touch (range, damage per landed power
   punch, counter exchanges, energy, the clinch...), the starting number, and which opponent style it should beat and which
   should beat it (a rock-paper-scissors table across all six).
2. Keep what the player sees: one line per style on the style card, plain game words (no jargon; say what it does).
3. Each lever must be a gain only when the style's moves are on the fighter's card (the map's three moves), never a stat buff.
4. End with the 10/10 list (owner rule S405).
