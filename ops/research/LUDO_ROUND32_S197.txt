5.3 Auto-Play Skip Rule (Meaningful, Transparent, Cost-Bearing)

Skipping a day executes the Assistant Coach Floor Delegation Algorithm. Skipping is never a silent black-box roll; it uses explicit mechanics that prevent accidental camp failure while demanding an intentional trade-off.

# Auto-Play Skip Computation Rule
func execute_day_skip(day: TrainingDay, fighter: Fighter, lead_coach: Coach):
    # Rule 1: The Competence Ceiling
    # Uncoached manual play achieves up to 120% efficiency via micro-management.
    # Delegated auto-play caps floor efficiency at 80% + (Coach.skill * 0.15)
    var delegation_efficiency: float = clamp(0.80 + (lead_coach.training_iq * 0.0015), 0.80, 0.95)
    
    # Rule 2: The Safety Governor
    # Auto-play strictly respects the Stamina Floor (default: 25).
    # If a fighter hits 25 stamina, the coach pulls them off stations and sends them to Stretch Mat.
    # COST: Fighter loses scheduled drill hours if stamina runs out early.
    var available_energy: float = fighter.stamina - 25.0
    var workable_hours: float = min(day.scheduled_hours, available_energy / fighter.stamina_burn_rate)
    
    # Rule 3: Missed Technique Gains
    # Move Cards require active coach intervention for Mastery advancement.
    # Auto-play generates only 50% Card Mastery XP, dumping remainder into flat attributes.
    fighter.apply_card_mastery_xp(workable_hours * 0.50)
    fighter.apply_attribute_gains(workable_hours * delegation_efficiency)
    
    # Rule 4: Wear & Injury Protection
    # Assistant coaches will never push into the red injury zone.
    # Risk of catastrophic structural injury during skip = 0.0%.
    fighter.accumulate_controlled_wear(workable_hours)
