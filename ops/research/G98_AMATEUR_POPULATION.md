What a registrar / club matchmaker sees

A federation registrar sees membership tiers (recreational vs carded), not a published bout histogram. A club matchmaker sees a BCR1 / passbook and matches experience bands the rulebook already defines (skills / 0-bout, novice 0–10, development 2–20, open/elite). Club nights try to pair 0 with 0. Most gym members never take a card. No NGB publishes shares in 0 / 1–2 / 3–5 / 6–10 / 11–20 / 20+. Tournament fields are the wrong sample (they are the survivors).

RECIPE (generate a region of N carded amateurs)

Use this only as a matching-world prior. Bands marked J are JUDGEMENT to make 0-vs-0 possible; they are not federation statistics.

Stock (carded competitive pool = N)

Scale from England/USA club math: ~16–20 carded per club, total gym members ≈ 1.6–2× carded. Recreational do not enter the opponent pool.

Bout-band prior for carded N (J unless noted)

| Band | Share of N | Role |
|---|---|---|
| 0 | 18–25% J | debut / FONO / skills-complete; must be matchable to other 0s |
| 1–2 | 18–22% J | still novice; most attrition happens here (France 54% beginner dropout is the only hard attrition number) |
| 3–5 | 15–18% J | USA/EB novice still |
| 6–10 | 15–18% J | novice ceiling (USA 0–10, WAKO 0–10) rule SOURCED |
| 11–20 | 12–16% J | EB Senior Dev window rule SOURCED |
| 20+ | 8–12% J | open/elite / champs regulars; tournament samples live here |

Do not draw a debutant opponent from the 20+ tail. Condition opponent draw on the same band (±1 band), the way BCR1 matching works.

Yearly flow (per 100 carded, J except where tagged)

New cards / year: 20–35 (membership is growing; competitive stock ~flat in England → high churn).
True debuts (bout 1): 15–25.
Quit before bout 3: 40–55% of debuts (only anchor: France 54% beginner dropout SOURCED; apply as J elsewhere).
Still active at 10 bouts: ~20–30% of debuts J.
Turn pro: a few % of the 20+ band, not of N.

Club novice count

For a club with C carded: novices (0–10) ≈ 0.55–0.65 × C under the table above. A 18-carded club → ~10 novices, of whom 3–5 are 0–2. That is the pool a debutant should draw from.

Age / weight / sex modifiers

First senior bout: mostly 18–24 if they did not box as youth; youth pipeline starts 10–17. Median NOT FOUND — do not invent one.
Weights: generate more mass in 57–75 kg; thin the tails (fly, heavy) so matchmakers fail more often there. Occupancy table NOT FOUND.
Sex: start ~75–85% male in the competitive pool (event fields SOURCED); do not treat that as gym-membership sex ratio.

Other sports (same N recipe, different class labels)

MT: map 0 / 1–2 / 3–5 / 6–11 / 12–17 / 18+ onto Novice–C–B–A–Elite. Shares NOT FOUND — reuse boxing prior.
WAKO: 0–10 Novice vs 11+ Open.
MMA: keep a 0–3 beginner class as a real matchmaking bin (EU amateur practice SOURCED); IMMAF worlds are not that class.

Verdict: Federations publish stock (clubs, members, carded ≈ 20k England / 46k USA athletes) and class rules (0–10 novice, Dev 2–20, skills ≤6, FONO). They do not publish bout-count histograms, debut counts, or attrition-by-bout. A world with nobody at 0–2 is not how club boxing is built. Generate the pyramid so a first-timer's opponent pool is other 0–2s in the same weight/sex, at ~3–5 such novices per typical club.
