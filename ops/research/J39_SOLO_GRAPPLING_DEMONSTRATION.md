### Coaching consensus (label: published consensus, not %).

Solo teaches: hip/base movement, entries, sprawls, ukemi, stance, conditioning, visualization.  
Solo does **not** teach: timing under resistance, weight distribution of a live body, grip fighting outcomes, submission *finish against a neck/limb that is not yours*, pin pressure, reactive scrambles.

## Q3 — REFUSAL LIST. What published instructors do **not** demo / practise as solo *named technique*

### Explicit refusals / hard exclusions (MEASURED)

| Category | Why (as they say) | Source |
|---|---|---|
| **Throws / live finishes** as solo practice | Safety + needs partner / coach progression | Titans Grip FAQ: practise throws alone? **No** |
| **Submissions** as solo practice | Same | Titans Grip FAQ |
| **Pinning combinations** as shadow | “It is difficult to shadow drill pinning combinations” — use visualization for top riding | Ken Chertow *Shadow Wrestling* |
| **Armbar / choke on empty air as full technique** | “no mechanical consequence”; “cannot choke yourself” | Fight Encyclopedia |
| **Penetration-step finish** (lift / turn / fall) in home solo | Explicitly excluded from solo plan | Titans Grip penetration block |
| **Hard sprawl impact / partner weight transfer** alone | Coordinate shape only; do not simulate collision | Titans Grip sprawl block |

### Contact-is-the-technique examples (armbar / kimura / collar choke)

| Technique | Solo “component” published? | Solo as *the named technique*? | Sources |
|---|---|---|---|
| **Armbar** | Hip extension / band-resisted finish motion | **No** — empty-air armbar lacks the controlled limb | Fight Encyclopedia Cat. 6; MartialBoss band drill; Evolve dummy recommended for finishes |
| **Kimura** | Grip shape / band motion occasionally listed in blog drills | **No** as full technique without limb | MartialBoss mentions kimura motion with bands; no federation solo kimura demo standard found |
| **Collar choke (gi)** | Grip on own collar / fabric awareness sometimes suggested | **No** — choke requires partner’s neck | Fight Encyclopedia physics line; gi solo “collar grip simulation” is proprioception, not the choke |
| **RNC** | Palm-to-bicep grip on **own** arm | Grip rehearsal only | Fight Encyclopedia |

### Broader refusal categories (MEASURED pattern across sources)

1. **Completed nage-waza / named throws** — uchi-komi stops before execution; nage-komi needs uke (Judo Channel).  
2. **Submissions whose definition is control of another’s joint/neck** — armbar, kimura, collar choke, triangles as *finishes*.  
3. **Pins / osaekomi / riding** — Chertow: hard to shadow.  
4. **Guard passes / sweeps as named techniques** — blogs teach *solo hip mechanics* (hip bump motion, butterfly lift) but still frame them as mechanics, often with pillow/dummy; live pass needs passer.  
5. **Anything requiring reactive timing** — universal coaching caveat.

## Q4 — CAMERA. When solo drills *are* filmed for instruction

### Conventions from instructional / self-film guides (MEASURED)

| Parameter | Practice | Source |
|---|---|---|
| **Angle** | Prefer **neutral** angles; avoid “fancy” cinematic angles. Side-on for depth (penetration, shrimp path); front for stance width / symmetry | Wim Demeere, “How to make instructional videos…” (2020-04-28); Titans Grip |
| **Distance / framing** | **Full body + travel path** in frame; wide first, then crop/close for detail; shoot 4K to crop | Demeere; Titans Grip “whole body and the space around your feet” |
| **Height** | Tripod stable; roughly hip–chest height common for self-film advice | Mobile-Squad / Replayr self-film guides (secondary); Demeere tripod emphasis |
| **Tempo** | Slow clean demo first; then working tempo; Chertow uses shadow for skill early-season and speed/conditioning later | Demeere “Speed of movement”; Chertow practice structure; Kingz “accuracy over speed” |
| **Floor marks** | **Tape / duct tape marks** for talent position and for penetration start line | Demeere “Mark the spot”; Titans Grip “Mark a start line with tape” |
| **Implied partner** | **Nothing** for shrimp / bridge / TSU / granby / ukemi | Kingz; Fight Encyclopedia |
| | **Tape line / mirror** for wrestling stance & hand-fight footwork | Titans Grip |
| | **Wall** as shot/posture prop | Evolve MMA wall walk-through |
| | **Resistance band / belt on pillar or tree** for judo uchi-komi & sambo grips | Judo Channel; Koka Kids; FIAS flash-mob elastic-band trees |
| | **Pillow / stuffed hoodie / dummy** when drilling “against” something | Kingz “Use Something as a Target”; Evolve dummy section; FIAS COVID dummy throws |
| **Clothing contrast** | Even colours, limbs distinguishable; avoid stripes | Demeere |
| **Self-review** | Film then watch; one question per angle | Titans Grip; Kingz |

### Prompt-facing summary for generation

For **true solo-named drills**: one actor, mat, **side or ¾**, full body, **slow→normal**, **no fake partner mesh**, optional **tape line** (wrestling entry) or **band/pillar** (judo uchi-komi).  
For **contact-is-the-technique** names: coaching literature does **not** treat empty-air as the technique — do not expect practitioner recognition of “armbar” from solo mime even if the clip is pretty.

## Q5 — ONE LINE RANK (named-technique survival solo)

**Trap respected:** rank by **practitioner recognition of the named technique**, not ease of filming.

### Ranking (INFERENCE built only on published patterns above)

| Rank | Art | Why (basis) | Denominator caveat |
|---|---|---|---|
| **1** | **Wrestling** | Large share of *named* skills are themselves solo forms: stance & motion, penetration step, sprawl, stand-up, sit-out, hip heist, granby. Chertow + USA Wrestling curricula treat shadow as first-class. Pins/top riding are the main refusal island. | Based on coaching literature density + named-drill overlap with technique names — **not** a % of UWW rulebook techniques |
| **2** | **Judo** | **Ukemi** fully survives as named solo. **Uchi-komi** survives as named *training method* (solo allowed). **Named throws** (seoi-nage, etc.) as completed techniques do **not** — need uke. Ne-waza pins/holds need partner. | Syllabus heavy on throws → large fraction of *technique names* need a second body |
| **3** | **Sambo** | Structurally judo-like throws + wrestling-like entries + ground; FIAS COVID shows bands/dummies/home work, **not** a published English solo technique syllabus. Recognition pattern **inferred** ≈ judo with thinner English documentation. | **Weakest source base** of the four |
| **4** | **BJJ** | Movement primitives (shrimp, bridge, TSU, granby, leg circles) are strongly named **as drills**, but the **commercial / belt syllabus technique names** (armbar, kimura, collar choke, pass X, sweep Y) are contact-defined. Solo armbar films; practitioners do not treat it as *the armbar*. | Highest count of contact-is-the-technique names in the 72-node BJJ slice |

### One-liner (Q5)

**Wrestling > Judo > Sambo > BJJ** for how much of the *named-technique* syllabus still reads as that named technique when shown solo — ranked on coaching/federation recognition patterns (shadow = technique vs mime), **not** on filmability.

## Judgement + INFERENCE candidates (labelled; not for gating without go)

1. **INFERENCE — Product rule:** Label clips as `SOLO_DRILL:<name>` when the name is a recognised solo drill (shrimp, ukemi, sprawl, penetration step…). Label `MIME:<technique>` or withhold generation when the catalogue name is a contact technique (armbar, kimura, collar choke, completed throw, pin).  
2. **INFERENCE — Credit:** Spend rare paired-generation / mocap / bought `_Att`/`_Vic` budget on **contact-is-the-technique** nodes first (aligns with C91 gold path + R144 scarcity). Solo generator is legitimate for the Q1 “yes” rows.  
3. **INFERENCE — Ranking implication for 189 grappling nodes:** Of operator’s slice (115 judo / 72 BJJ / 18 wrestling / 18 sambo), **wrestling’s 18** are the densest “solo may still be the named thing”; **BJJ’s 72** are the densest “solo will not read as the named technique.” Judo 115 split: ukemi/entry vs throws. Sambo 18: treat like judo until FIAS syllabus found.  
4. **INFERENCE — Camera prompts:** Default side-on full-body, mat, no second mesh, optional tape line; add band/pillar only for uchi-komi-class; never imply a ghost partner for shrimp-class.  
5. **NOT an INFERENCE to promote:** “Anyone can reason armbar needs a partner” as the *answer* — the memo documents what instructors/federations **actually publish**, which concurs but is sourced.

## One-liner (whole memo)

**Solo grappling demos read when the catalogue name is already a published solo drill (shrimp, ukemi, sprawl, shot-step…); they do not read as the named technique when contact *is* the technique (armbar, kimura, collar choke, completed throw, pin) — and coaching literature already refuses or fences those off.**
