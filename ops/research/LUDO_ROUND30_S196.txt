1.3 The Attrition Hourly Processing Formula

For any fighter $f$, training station $s$, and body region $r$, during continuous time duration $\Delta t$ (hours):

$$\Delta \text{Integrity}(f, r, s) = -\left[ \text{BaseRate}(s, r) \times \Phi_{\text{Form}}(f) \times \Psi_{\text{Hardware}}(s) \times \Omega_{\text{Vuln}}(f, r) \times \Delta t \right]$$

Where:

Form Decay Factor ($\Phi_{\text{Form}}$):
$$\Phi_{\text{Form}}(f) = 1.0 + \left( \frac{\max(0, 40.0 - \text{Stamina}_t)}{40.0} \right)^2 \times 1.8$$
(When stamina drops below 40.0, mechanical form breaks down non-linearly, up to a $2.8\times$ damage multiplier at $0$ stamina).

Hardware Defect Factor ($\Psi_{\text{Hardware}}$):
$$\Psi_{\text{Hardware}}(s) = 1.0 + \left( \frac{\max(0, 70.0 - \text{Integrity}_{\text{Equip}}(s))}{70.0} \right) \times 1.4$$
(Worn equipment forces compensatory joint torque and delivers erratic mechanical resistance).

Athlete Specific Vulnerability ($\Omega_{\text{Vuln}}$):
$$\Omega_{\text{Vuln}}(f, r) = \text{TraitMod}(f, r) \times \text{AgeMod}(f) \times \text{HistoryMod}(f, r) \times \text{WeightCutMod}(f)$$

Chronic Joint Load Increment ($\Delta \text{Joint}$):
$$\Delta \text{Joint}(f, s) = \left[ \text{BaseJointRate}(s) \times \left(1.0 + \frac{100.0 - \text{Conditioning}(f)}{200.0}\right) \times \left(1.0 + \frac{\text{Weight}(f) - 60.0}{140.0}\right) \right] \times \Delta t$$

2. Accumulation and Recovery Mechanics

Athletic training balance relies on Bannister’s Fitness-Fatigue model, implemented via the Acute:Chronic Workload Ratio (ACWR).

                  ACWR (Acute-to-Chronic Workload Ratio)
      0.0         0.8                1.3         1.5                 2.0+
       [-----------[==================]-----------[-------------------]
        Detraining     "Sweet Spot"     Overreach     CRITICAL HAZARD
        High Floor     Lowest Injury   Functional     Injury Probability
        Decay Rate     Probability     Gains          Spikes Exponentially

2.1 Acute Load vs. Chronic Load Definitions
Acute Workload (Rolling 7-day average): Reflects immediate athletic fatigue: $$\text{AcuteLoad}{d} = 0.25 \times \text{DailyStrain}{d} + 0.75 \times \text{AcuteLoad}_{d-1}$$
Chronic Workload (Rolling 28-day average): Represents physical fitness foundation: $$\text{ChronicLoad}{d} = 0.07 \times \text{DailyStrain}{d} + 0.93 \times \text{ChronicLoad}_{d-1}$$
Coupled Ratio: $$\text{ACWR}_d = \frac{\text{AcuteLoad}_d}{\max(1.0, \text{ChronicLoad}_d)}$$
Ratio Thresholds and Systematic Rules:
$\text{ACWR} < 0.8$: Under-training zone. Injury hazard baseline ($0.02%/\text{h}$); physical attribute retention degrades by $-0.15%/\text{day}$.
$0.8 \le \text{ACWR} \le 1.3$: Optimal conditioning. Injury hazard baseline ($0.01%/\text{h}$); skill/stat adaptation efficiency at $1.0\times$ to $1.15\times$.
$1.3 < \text{ACWR} \le 1.5$: Overreach. Adaptive gains continue, but cumulative joint degradation increases by $+40%$.
$\text{ACWR} > 1.5$: Critical hazard. Structural tissue integrity loss scales: $$\text{TissueDamageMult} = 1.0 + (\text{ACWR} - 1.5) \times 3.0$$
$\text{ACWR} \ge 2.0$: Structural failure zone. Soft-tissue rupture hazard per hour spent on high-load stations increases to $4.8%$.

3.3 Historical Trauma Multiplier ($\text{HistoryMod}$)

Each documented historical injury leaves lasting structural vulnerability on that region:
$$\text{HistoryMod}(f, r) = 1.0 + \sum_{i \in \text{Injuries}(r)} \text{SeverityWeight}(i)$$

Minor sprain/strain: $+0.08$
Grade II muscle tear: $+0.22$
Ligament rupture / Surgical reconstruction: $+0.55$
Bone fracture (clean heal): $+0.05$ (calcification benefit balances soft-tissue scarring)

4.2 Hard Safety Auto-Pause Conditions

The simulation loop halts execution under three explicit conditions:

Critical Regional Compromise: Any body region drops below $20.0$ integrity during an active drill.
Exhaustion Threshold: Daily stamina drops below $15.0$ while assigned to any non-recovery station.
Hardware Breakdown Risk: Station integrity drops below $20.0%$ while occupied by a contracted fighter.

When paused, the manager must choose one of three actions:

Option A: Pivot. Re-route athlete to an unassigned low-impact or recovery station (e.g., convert Heavy Bag run to Slip Rope or Technical Shadowboxing).
Option B: Terminate Session. Send athlete directly to passive rest/baths (forfeits remaining progression gains; stabilizes tissue wear).
Option C: Override (Force Through). Require athlete to complete the assigned protocol. Applies a permanent $-15$ Composure penalty, spikes catastrophic injury risk by $6.0\times$, and triggers an immediate compliance/morale check.

7.3 Pure Engine Module: AttritionProfile.gd
# Resides at: res://scripts/sim/AttritionProfile.gd
# Pure static computation module. Godot 4.7.
# Independent of scene trees or global state. Deterministic calculations.
class_name AttritionProfile
extends RefCounted

const REGIONS: Array[String] = [
	"head_neck", "torso_core", "left_arm", 
	"right_arm", "left_leg", "right_leg"
]

static func calculate_form_decay(current_stamina: float) -> float:
	if current_stamina >= 40.0:
		return 1.0
	var deficit: float = (40.0 - current_stamina) / 40.0
	return 1.0 + (deficit * deficit * 1.8)

static func calculate_hardware_defect(hardware_integrity: float) -> float:
	if hardware_integrity >= 70.0:
		return 1.0
	var deficit: float = (70.0 - hardware_integrity) / 70.0
	return 1.0 + (deficit * 1.4)

static func calculate_age_modifier(age: int) -> float:
	if age <= 23:
		return 0.85
	elif age <= 29:
		return 1.0
	elif age <= 34:
		return 1.25
	else:
		return 1.55

static func calculate_acwr_multiplier(acute_load: float, chronic_load: float) -> float:
	var baseline_chronic: float = maxf(1.0, chronic_load)
	var acwr: float = acute_load / baseline_chronic
	if acwr <= 1.3:
		return 1.0
	elif acwr <= 1.5:
		return 1.0 + ((acwr - 1.3) * 0.5)
	else:
		return 1.1 + ((acwr - 1.5) * 3.0)

static func process_training_step(
	fighter: Dictionary,
	station_profile: Dictionary,
	hardware_integrity: float,
	duration_hours: float,
	rng_stream: RandomNumberGenerator
) -> Dictionary:
	var result: Dictionary = {
		"region_deltas": {},
		"cns_delta": 0.0,
		"joint_delta": 0.0,
		"stamina_cost": 0.0,
		"critical_safety_stop": false,
		"stop_reason": ""
	}
	
	var form_factor: float = calculate_form_decay(float(fighter.get("stamina", 100.0)))
	var hard_factor: float = calculate_hardware_defect(hardware_integrity)
	var age_factor: float = calculate_age_modifier(int(fighter.get("age", 25)))
	var acwr_factor: float = calculate_acwr_multiplier(
		float(fighter.get("acute_load", 10.0)),
		float(fighter.get("chronic_load", 10.0))
	)
	
	var base_rates: Dictionary = station_profile.get("base_rates", {})
	var fighter_regions: Dictionary = fighter.get("regions", {})
	var trait_mods: Dictionary = fighter.get("trait_mods", {})
	var history_mods: Dictionary = fighter.get("history_mods", {})
	
	# Process regional integrity
	for region in REGIONS:
		var base_rate: float = float(base_rates.get(region, 0.0))
		if base_rate < 0.0:
			var t_mod: float = float(trait_mods.get(region, 1.0))
			var h_mod: float = float(history_mods.get(region, 1.0))
			var delta: float = base_rate * form_factor * hard_factor * age_factor * t_mod * h_mod * acwr_factor * duration_hours
			result["region_deltas"][region] = delta
			
			var projected: float = float(fighter_regions.get(region, 100.0)) + delta
			if projected < 20.0:
				result["critical_safety_stop"] = true
				result["stop_reason"] = "REGIONAL_INTEGRITY_BREACH_" + region.to_upper()
		else:
			# Positive recovery rates bypass fatigue penalties
			result["region_deltas"][region] = base_rate * duration_hours
			
	# CNS Burnout Delta
	var cns_base: float = float(base_rates.get("cns_burn", 0.0))
	result["cns_delta"] = cns_base * duration_hours * (1.0 if cns_base > 0.0 else form_factor)

	var weight_mod: float = 1.0 + ((weight - 60.0) / 140.0)
	result["joint_delta"] = joint_base * cond_mod * weight_mod * hard_factor * duration_hours
	
	# Stamina Expenditure

	result["stamina_cost"] = base_stamina_drain * duration_hours

7.2 Complete Static API Implementation (AttritionProfile.gd)
# res://scripts/sim/AttritionProfile.gd
class_name AttritionProfile
extends RefCounted

const REGIONS: Array[String] = [
	"head_neck", "torso_core", "left_arm", 
	"right_arm", "left_leg", "right_leg"
]

const MIN_STAMINA_EMERGENCY_HALT: float = 15.0
const MIN_REGION_INTEGRITY_HALT: float = 20.0
const HARDWARE_SAFETY_HALT: float = 20.0

static func calculate_form_decay(current_stamina: float) -> float:
	if current_stamina >= 40.0:
		return 1.0
	var deficit: float = (40.0 - maxf(0.0, current_stamina)) / 40.0
	return 1.0 + (deficit * deficit * 1.8)

static func calculate_hardware_defect(hardware_integrity: float) -> float:
	if hardware_integrity >= 70.0:
		return 1.0
	var deficit: float = (70.0 - maxf(0.0, hardware_integrity)) / 70.0
	return 1.0 + (deficit * 1.4)

static func calculate_age_modifier(age: int) -> float:
	if age <= 23:
		return 0.85
	elif age <= 29:
		return 1.00
	elif age <= 34:
		return 1.25
	else:
		return 1.55

static func calculate_acwr_multiplier(acute_load: float, chronic_load: float) -> float:
	var baseline_chronic: float = maxf(1.0, chronic_load)
	var acwr: float = acute_load / baseline_chronic
	if acwr <= 1.3:
		return 1.0
	elif acwr <= 1.5:
		return 1.0 + ((acwr - 1.3) * 0.5)
	else:
		return 1.1 + ((acwr - 1.5) * 3.0)

static func evaluate_step(
	fighter: Dictionary,
	station_profile: Dictionary,
	hardware_integrity: float,
	duration_hours: float,
	rng: RandomNumberGenerator
) -> Dictionary:
	var output: Dictionary = {
		"region_deltas": {},
		"cns_delta": 0.0,
		"joint_delta": 0.0,
		"stamina_cost": 0.0,
		"injury_triggered": false,
		"injury_region": "",
		"critical_safety_stop": false,
		"stop_reason": "NONE"
	}
	
	if hardware_integrity < HARDWARE_SAFETY_HALT:
		output["critical_safety_stop"] = true
		output["stop_reason"] = "HARDWARE_FAILURE_RISK"
		return output

	var cur_stamina: float = float(fighter.get("stamina", 100.0))
	var base_drain: float = float(station_profile.get("stamina_drain_per_hour", 15.0))
	var total_stamina_cost: float = base_drain * duration_hours
	output["stamina_cost"] = total_stamina_cost
	
	if (cur_stamina - total_stamina_cost) < MIN_STAMINA_EMERGENCY_HALT:
		output["critical_safety_stop"] = true
		output["stop_reason"] = "STAMINA_EXHAUSTION_CRITICAL"
		return output

	var form_mult: float = calculate_form_decay(cur_stamina)
	var hard_mult: float = calculate_hardware_defect(hardware_integrity)
	var age_mult: float = calculate_age_modifier(int(fighter.get("age", 25)))
	var acwr_mult: float = calculate_acwr_multiplier(
		float(fighter.get("acute_load", 10.0)),
		float(fighter.get("chronic_load", 10.0))
	)

	var base_rates: Dictionary = station_profile.get("base_rates", {})
	var f_regions: Dictionary = fighter.get("regions", {})
	var t_mods: Dictionary = fighter.get("trait_mods", {})
	var h_mods: Dictionary = fighter.get("history_mods", {})

	for r in REGIONS:
		var base_rate: float = float(base_rates.get(r, 0.0))
		if base_rate < 0.0:
			var tm: float = float(t_mods.get(r, 1.0))
			var hm: float = float(h_mods.get(r, 1.0))
			var delta: float = base_rate * form_mult * hard_mult * age_mult * tm * hm * acwr_mult * duration_hours
			output["region_deltas"][r] = delta
			
			var projected: float = float(f_regions.get(r, 100.0)) + delta
			if projected < MIN_REGION_INTEGRITY_HALT:
				output["critical_safety_stop"] = true
				output["stop_reason"] = "REGIONAL_INTEGRITY_COMPROMISED_" + r.to_upper()
		else:
			output["region_deltas"][r] = base_rate * duration_hours

	var cns_base: float = float(base_rates.get("cns_burn", 0.0))
	if cns_base < 0.0:
		output["cns_delta"] = cns_base * form_mult * age_mult * duration_hours
	else:
		output["cns_delta"] = cns_base * duration_hours

	var j_base: float = float(base_rates.get("joint_load", 0.0))
	if j_base > 0.0:
		var cond: float = float(fighter.get("conditioning", 50.0))
		var w_kg: float = float(fighter.get("weight_kg", 70.0))
		var cond_fact: float = 1.0 + ((100.0 - cond) / 200.0)
		var w_fact: float = 1.0 + ((w_kg - 60.0) / 140.0)
		output["joint_delta"] = j_base * cond_fact * w_fact * hard_mult * duration_hours
	else:
		output["joint_delta"] = j_base * duration_hours

	var base_inj_rate: float = float(station_profile.get("base_injury_risk_per_hour", 0.005))
	var step_inj_prob: float = base_inj_rate * form_mult * hard_mult * acwr_mult * duration_hours
	if rng.randf() < step_inj_prob:
		output["injury_triggered"] = true
		var target_idx: int = rng.randi_range(0, REGIONS.size() - 1)
		output["injury_region"] = REGIONS[target_idx]

	return output

C.2 Monthly Member Lifecycle Model
       [Unaware Local Market Pool]
                   │
                   ▼ (Marketing, Reputation, Density, Pricing)
            [Inbound Inquiries]
                   │
                   ▼ Trial Class / Conversion Rate ($E_{\text{conv}}$)
            [Active Members] ◄──────┐
               │           │        │
 (Check-in = 0)│           ▼        │ Reactivation
               │    [Retention /    │ ($H_{\text{react}}$)
               ▼       Hazard]      │
           [Sleepers]      │        │
               │           ▼        │

1. Acquisition Rate ($\Delta M_{\text{in}}$)

$$\Delta M_{\text{in}} = \text{floor}\left( \text{MarketPool} \times P_{\text{capture}} \times E_{\text{conv}} \right)$$

Local Target Pool ($\text{MarketPool}$): Base urban district density $= 3,500$ prospective sports/fitness enthusiasts per km² within a 3 km catchment $= 10,500$ addressable leads.
Capture Probability ($P_{\text{capture}}$):

$$P_{\text{capture}} = \left( \frac{\text{Reputation}}{100} \times 0.025 \right) + \left( \frac{\text{MarketingSpend}}{1000} \times 0.015 \right) - \left( N_{\text{rivals}} \times 0.003 \right)$$

Conversion Elasticity ($E_{\text{conv}}$):

$$E_{\text{conv}} = \text{clamp}\left( 0.15 + (Q_{\text{coach}} \times 0.003) + (C_{\text{clean}} \times 0.002) + (V_{\text{equip}} \times 0.002) - (\text{PriceIndex} \times 0.25),, 0.05,, 0.85 \right)$$

Where:

$Q_{\text{coach}}$: Mean coaching staff quality rating ($0\text{--}100$).
$C_{\text{clean}}$: Gym hygiene and cleanliness rating ($0\text{--}100$).
$V_{\text{equip}}$: Equipment variety score (ratio of distinct functional families installed, $0\text{--}1.0$).
$\text{PriceIndex}$: $\frac{\text{GymBasePrice}}{\text{DistrictBenchmarkPrice}}$ (baseline $= 1.00$).
2. Retention & Churn Hazard Function

For each active member, monthly churn hazard $H_i$ is computed:

$$H_i = H_{0,i} \times \left(1.0 + \sum \text{Hazards}\right)$$

$$H_i = H_{0,i} \times \left(1.0 + \Phi_{\text{crowd}} + \Phi_{\text{hygiene}} + \Phi_{\text{coach}} + \Phi_{\text{broken}} + \Phi_{\text{dispute}} - \Psi_{\text{fighter_star}}\right)$$

$H_{0,i}$: Base archetype monthly churn (from monthly_churn_base, e.g., $0.04\text{--}0.14$).
$\Phi_{\text{crowd}}$: Crowding penalty $= \max\left(0.0,, \frac{\text{PeakDensity} - 0.75}{0.25}\right) \times 1.50$.
$\Phi_{\text{hygiene}}$: Cleanliness deficit $= \max\left(0.0,, \frac{E_{\text{clean_min}} - C_{\text{clean}}}{100}\right) \times 2.00$.
$\Phi_{\text{coach}}$: Coach quality deficit $= \max\left(0.0,, \frac{E_{\text{coach_min}} - Q_{\text{coach}}}{100}\right) \times 1.75$.
$\Phi_{\text{broken}}$: Broken equipment encounter multiplier $= \left(\frac{N_{\text{broken_encounters}}}{N_{\text{visits}}}\right) \times 1.25$.
$\Phi_{\text{dispute}}$: Unresolved member incident/dispute mark $= 0.50$ per open complaint.
$\Psi_{\text{fighter_star}}$: Active champion prestige discount $= \left(\frac{\text{Prestige}}{100}\right) \times 0.25$.

If a member records $0$ check-ins for 30 consecutive days, they transition to sleeper status:

Sleeper base churn $= 0.22/\text{month}$.
Sleepers generate $0$ floor wear and $0$ crowding load, but maintain automatic direct-debit billing until cancellation.
3. Reactivation Pipeline ($H_{\text{react}}$)

Win-back campaigns targeting churned members within 90 days:

Cost: $$15$ per contact.
Success Rate $= \text{clamp}\left(0.08 + (C_{\text{clean_current}} - C_{\text{clean_exit}})\times 0.005 + (\text{Reputation} \times 0.001),, 0.02,, 0.35\right)$.
C.3 Daily Usage Simulation & Fighter Priority Conflicts

Operating schedule: 10 operational hours daily ($07:00\text{--}17:00$ or $11:00\text{--}21:00$), evaluated across 10 discrete 60-minute time blocks ($h = 0 \dots 9$).

1. Hourly Arrival Distribution

Given active roster size $M_{\text{active}}$, check-in arrivals for archetype $k$ at hour $h$ follow Poisson parameter $\lambda_{k,h}$:

$$\lambda_{k,h} = M_k \times \left(\frac{\text{Freq}k}{7}\right) \times W{k}(h)$$

Where $W_{k}(h)$ is the hourly probability mass normalized from peak_arrival_windows.

2. Station Selection & Queue Dynamics
A member enters and attempts to claim a station within preferred_zones.
Occupancy Evaluation: If a station has available capacity ($N_{\text{current}} < \text{station_capacity}$), member claims slot.
Queue Invariant: If all preferred stations are full:
Member enters the zone queue.
Member queue tolerance clock decrements: $\text{WaitRemaining} = \text{queue_patience_minutes} - \Delta t_{\text{wait}}$.
If $\text{WaitRemaining} \le 0$: Member exits unsatisfied (Event: Walkout), adding $+0.05$ to individual churn hazard and $-0.10$ gym satisfaction.

Members degrade equipment at identical physical touchpoints to fighters, scaling directly by archetype weight and volume.

$$\Delta I_j = \sum_{m \in \text{Occupants}_j} \left( \text{wear_per_hr}j \times \mu{\text{wear},m} \right)$$

Where:

$\text{wear_per_hr}_j$ is the base machine hardware decay rate defined in Section B.
$\mu_{\text{wear},m}$ is the archetype multiplier (e.g., $1.85$ for active competitors, $0.50$ for seniors).
