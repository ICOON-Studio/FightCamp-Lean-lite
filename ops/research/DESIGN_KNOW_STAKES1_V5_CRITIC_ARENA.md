# KNOW_STAKES1_V5 — independent boxing design review

SCORE depth=7 general=7

- **Depth: 7/10.** The same note can change whom you book, what you spend a pad night on, and which instruction gets the next round's attention. Giving up a night that would make a move Usable is a real cost; a habit that rarely comes up should not win that trade. Taking a difficult booking can still be right for the money, a goal or a rank. But the corner can erase a recurring debit and restore access to the live read for the same slot. If the opponent keeps pressing and there is no comparable reason to change the defence, repeating the same fix is close to automatic. Quick fixes, four paid nights and the signing shortcut need to compete on the same terms.
- **General design: 7/10.** Week, film, Playbook, corner and Why are the right homes. Knowledge is best when it changes what the coach does, not when it buys a purse bonus. But the map treats style share as exposure, uses ring language for triggers the engine doesn't check, and leaves the existing film bonus and automatic reveals unaccounted for. Those are settlement and scheduling decisions, not copy edits. Buildable in slices; not ready to implement as written.
- **Play: 7/10.** A note worth testing, a drill that costs something this week and a bell that tells you whether it paid give the player a reason to come back. The best payoff is seeing a choice protect your boxer even in a loss. Four identical clicks and a film miss that teaches nothing would turn that loop into chores. Let a quiet week stay one click; report progress in the existing review.

## Code check — section 1, in map order

1. **FighterProfile / CoachNotes / Sim — yes.** Two distinct entries from a shuffled pool; ownership is separate from notes. A fight reveal picks first unseen (habits before notable traits), film filters to habits, and sparring rolls below 0.35 before picking. The coached call is at `Sim.end_week` around line 398; it does not test that a spar happened. There is also a twist call around line 74. Moving the decision to a completed coached spar is new work, not just raising odds.
2. **HabitFix — yes with terminology caveat.** There are 17 situation-keyed IDs, two clock IDs and one uncharged ID, not 17 distinct situations. First matching owned ID wins. The three examples are keyed to press/counter/press, slow start is round one at indices 0–1, and fade starts at index 3 in the last round. Seen and owned are both required by `offers`; fade qualifies even when the next round isn't final, whereas slow start and the helpful body habit do not. The JSON gives descriptive triggers; the code does not require a jab, touching ropes, or actually being ahead for the respective mode-keyed debits.
3. **LiveRound / HabitFix / Exchanges — yes on the live path.** `6 × 1.75 = 10.5` margin points; an unmatched punished habit blocks normal `LiveRead.read_fire`, not every possible read-based effect (the separate NOW path can still add a read edge). The named match zeros the debit and removes that blocker; it doesn't guarantee a read. Uptake is `0.7 + 0.3 × clamp(coachability, 0, 100)/100`, halved for shouts beyond the first two and multiplied by trust on the call path. The fallback uses zero prior shouts and a hot factor of 0.5; hold doesn't change a mismatch. `HabitFix.cost` alone can compute partial relief, but the live matching branch bypasses that calculation.
4. **LiveRound.close / HabitFix.result — yes, scoped to own habits.** Counts unmatched punished IDs and adds missing notes; separately counts matches and returns uptake times trust as `fix_hold`. Result text clamps and rounds that hold, not actual margin saved. Own note knowledge without a fix doesn't refund a debit. Don't generalize this to opponent film (see item 8).
5. **Recruit / Sim / FightAnalysisOwn — yes.** Signing habit focus schedules the first ID, with four-week due date; alternatives add 10 signature mastery (if a signature exists) or 5 potential, capped at 100/99. Own film can schedule the matched ID if there is no active fix; weekly settlement deletes the due ID. Neither counts drills; neither setter tests for an actual debit.
6. **KnowReads — yes at rules level.** Prices in order are $120 / $60 / $500 / $40 / $0 / $160 as described. Look closer clears hype or attempts to narrow the widest eligible group, not a player-selected group. Test day doubles exposure below five bouts, not necessarily the change in the range. Trial adds 24 body and skills exposure each, plus 8 under-fire spar exposure if open, subject to knowledge rules. Recheck applies to stale knowledge; the hard-spar risk function returns ×2 and +15 as screen data, not proof either is charged by this function. These are attribute reads, not habit reveals. `KnowWire` likewise updates attribute exposure around training, bouts and stale weeks.
7. **RoundStyle / OppFile / ModeTells — partly.** Word matching produces up to two distinct IDs. Weapon, ranked non-free mode, habits, next non-free mode, weakness is the intended order; `ModeTells.order` includes zero-show candidates and `OppFile.tells` drops them. Full tape opens the first hidden row; two `half_tape` calls open one, but `tape` itself doesn't consume a stored half. `remember` unions both found IDs and opponent notes into a nonempty rival record. The opponent does have `notes_seen` on its own file: `open` copies habit IDs there as well as to `file_found`. It doesn't write into your boxer's notebook.
8. **PlanLines — yes for the seven lookups and the line-strength calculation; incomplete for fight settlement.** Fade, slow start and admiring work map to tiring; dropped right to range; lunging jab to press; digging to the body and loading up when hurt to hurt. `strength` sums eligible line value minus its place mean. Opening a tell doesn't change that sum. It **can** change the night's base edge with an unchanged plan or drilled combination: `FilmEdge.answered` counts found tells already answered, and `LiveRound.open` applies `BoutRules.night_edge` (+0.4 per answer up to +1.2). It can count several tells answered by the same existing line. The map's blind/known-but-unused equality check must distinguish an uncovered tell from an already-covered tell.

## To reach 10/10

1. **Make every note true and every answer executable.** Start with one mode habit, one actual ring-place habit and the two clock habits. Share a trigger resolver across settlement, film evidence, forecast and corner recap; specify whose state it reads and when that state is sampled. If a move or ring event isn't available at settlement, describe the proxy honestly or hold that habit back. Store effective debit without the fix, actual debit, and normal-read eligibility separately; first-match ordering must not silently hand protection to a second habit. Show final-round results in Why as well as the bell recap. Decide whether the existing film base bonus is being retained and shown, or removed for this path; prefer removing the automatic reveal bonus and paying through the executed line.
2. **Charge one real resource once.** Credit at most one completed coached pad slot per habit per week, 25% of initial debit each time, no credit if displaced by rest or injury. Carry progress through pauses, make a retired ID unavailable for new fixes, and preserve a historical note. Move the signing focus onto that same scheduler with visible cost and migrate old timers without silently deleting a habit. For watched spar and either kind of film, reserve one existing evening and settle only the actual activity. Replace overlapping automatic payouts; key half-film progress to the opponent and study purpose so changing targets can't turn one half into unrelated evidence. Don't rebuy a confirmed fact or reroll the same film.
3. **Make the next decision comparable.** For booking, show a coarse estimate and its source beside cash/date/goal, never instead of eligibility. For corner advice, estimate the next round from eligible exchanges, current state and the plan, not last round's count alone; display uncertainty and never expose an unconfirmed ID. Explicitly gate opening and final-round fixes by the actual round. Put habit fixes and competing defensive changes on one comparable choice row. For a full plan, show the line being displaced, the mastery requirement and the affected place/condition before committing.
4. **Test for choices that reverse, not just an average win target.** Before tuning, require exact trigger/debit/read ledger tests, including both habits eligible, missed drill, early stoppage, longer bout, fix mismatch, and no exposure. Pair seeds and report confidence intervals by habit and matchup; compare drills, ordinary mastery and rest, then fixes versus defensive alternatives at equal instruction budgets. Separate a reveal that is already answered from one with no answer. Test booked and skipped fights across several career starts and coach budgets: a choice should win in one plausible case and lose in another. A fixed four-win target is a calibration guess, not a pass condition for every habit. This review ran neither the bot nor Godot.
5. **The finished page at 1920×1080.** Use the existing Fight prep page, not another tab. Keep the global bar at the top; put each boxer's name once in the matchup header beneath it, with date, weigh-in and next decision. Under that, use a left column for evidence (one own note and one opponent tell, sample and trigger), a central column for two plan choices (keep current line or preview a trained replacement), and a right column for the week cost (the pad slot, displaced gain and what will be ready by the bout). Leave the bottom strip for the existing next action; after the bout, use the same row order in Why: “Triggered twice · 15.75 of 15.75 margin points prevented · read available both times,” for two matches after one completed drill, if neither read was otherwise blocked. Keep missing evidence as text, not a disabled button. In the dark corner view reuse only the next-round comparison, not the whole page. The player should be able to point to what was known, what was given up and what changed.
