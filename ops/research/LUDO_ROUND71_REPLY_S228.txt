PART A: DEFECT CENSUS (AUDIT OF ATTACHED SCREENSHOT)

Comparing the attached Week 1 Gym Roster capture against the Round 70 UI Bible (#0d0c0b void, #1a1816 canvas, #22201d surface, #282521 card, brass border tokens, #f0c233 Championship Gold accents, 4px corner radii, 36px tabs with active underline, standardized typography and tooltips):

Tab Bar Misalignment and Token Violation (Top-Right Sub-Nav):

Observed: The ROSTER | FLOOR | STORE segmented pill bar sits in the upper right (x≈1630, y≈130) rendered in cyan/teal neon fill (#00e5ff tint), completely violating the Round 70 brand palette.
Bible Conflict: All sub-navigation tabs must use the 36px tall tab standard: transparent background, #a8a29e text, 2px bottom border #f0c233 on active selection, no rounded pill/bubble container.

Unanchored Empty State ("NOBODY IN THE BUILDING"):

Observed: A generic grey shooting-target dummy silhouette sits next to an unstyled headline NOBODY IN THE BUILDING with a dim subtitle SCOUTING FINDS THEM - THE FLOOR IS WAITING.
Bible Conflict: There is zero clear call-to-action (CTA). The user is stranded. It fails to provide an immediate interactive portal or primary button (#f0c233 CTA: [ SCOUT FREE AGENTS ] or [ POST LOCAL TRYOUT ]). The empty state card is a featureless, flat, washed-out horizontal panel without the standard #22201d surface fill, #3d372e 1px brass stroke, or 4px radius.

Sub-Header Metadata Redundancy & Clutter:

Observed: ANVIL STREET GYM · LONDON · FAME 0 · ROSTER 0 sits as tiny low-contrast uppercase text under the giant GYM title, and immediately below it sits another chip saying DAY ONE - ROSTER 0 - FLOOR READY.
Bible Conflict: Duplicated information (ROSTER 0 appears twice within 40 vertical pixels). Wastes valuable layout vertical budget. Header should adhere to the single unified breadcrumb standard: GYM / SQUAD (0/8).

Filter Chips Violate Round 70 Token Standards:

Observed: ALL, NEEDS YOU, BOOKED, OPEN BOOK are rendered as pill-shaped buttons with cyan border outlines and dark interiors.
Bible Conflict: Round 70 design tokens mandate rectangular 4px radius chips, 28px height, #1a1816 background, #332f27 brass stroke. Selected chip must have a solid border #f0c233 with gold text #f0c233 and subtle 10% gold background tint, not cyan wireframes.

Table Column Header Typography & Contrast:

Observed: Column headers (FIGHTER, RECORD, COND, MORALE, WEIGHT, PLAN, NEXT BOUT, FLAG) are rendered in mid-gray all-caps with uneven horizontal tracking, low contrast against the void backdrop, and an oversized down-triangle sort arrow next to COND that crowds the text.
Bible Conflict: Headers must be set in 11px uppercase bold (#8c8273 Muted Brass), tabular alignment matching row cells, with a dedicated 12px SVG chevron icon with 4px left margin.

Missing Stance and Contract Columns:

Observed: The table headers in the screenshot show MORALE, PLAN, and FLAG, omitting STANCE (Orthodox/Southpaw) and CONTRACT (weekly wage / bouts remaining), which are critical tactical and financial data points specified in the screen brief.

Extraneous Top-Left Plus Icon:

Observed: A lone + icon sits isolated inside a grey square button at x=52, y=94 right above the word GYM.
Bible Conflict: Orphaned floating utility button with no label, no tooltip, and no established grid alignment. Recruitment actions belong inside the primary empty state and the top-right header action zone.

Guidance Toast Clashing with Canvas ("GUIDE - Sign your first boxer"):

Observed: A bright yellow floating pill sits at bottom right (x≈1550, y≈945) detached from the content area.
Bible Conflict: Floating guide tags clutter the screen edges and collide with bottom utility bars. The roster empty state itself must natively convey the primary action rather than relying on an out-of-flow overlay.

PART C: INDUSTRY SQUAD-LIST BENCHMARKS & BEST PRACTICES
1. Football Manager (Sports Interactive)
What FM does: FM uses high-density table rows packed with tactical condition pies, morale icons, playing duty markers, and training workload warnings.
What we take: The "Attention/Duty State" flag. Instead of making the player click into each boxer to see if they are idle, a dedicated column and row pip flags boxers who have no training scheduled today or whose contract expires in under 4 weeks.
2. Motorsport Manager (Playsport Games)
What MM does: Uses visual card-row hybrids for drivers and mechanics. Displays clear contract expiration counters and weekly wage drain right alongside their performance rating.
What we take: The Contract & Wage presentation. In FightCamp, managing cash runway is crucial. Showing $1,200/wk · 2 bouts remaining directly on the squad list prevents sudden unexpected contract lapses without requiring manual drill-downs.
3. Two Point Campus / Hospital (Two Point Studios)
What Two Point does: Employs actionable empty states when a department has zero staff. It doesn't merely state "No Doctors"; it places a direct button reading "Hire Doctor" inside the vacant roster frame.
What we take: The Direct Action Empty State. Never strand the player with descriptive text alone. The empty screen is converted into an active onboarding gateway with primary action buttons.

class_name FighterRosterRow
extends PanelContainer

signal fighter_selected(fighter_id: String)
signal activity_change_requested(fighter_id: String, global_pos: Vector2)

# Round 70 Design System Tokens
const COLOR_VOID: Color = Color("#0d0c0b")
const COLOR_BG_NORMAL: Color = Color("#1a1816")
const COLOR_BG_HOVER: Color = Color("#22201d")
const COLOR_BG_SELECTED: Color = Color("#282521")
const COLOR_BORDER_DEFAULT: Color = Color("#282521")
const COLOR_BORDER_HOVER: Color = Color("#3d372e")
const COLOR_GOLD: Color = Color("#f0c233")
const COLOR_TEXT_CREAM: Color = Color("#f5f0e6")
const COLOR_TEXT_MUTED: Color = Color("#a8a29e")
const COLOR_STATUS_GREEN: Color = Color("#22c55e")
const COLOR_STATUS_AMBER: Color = Color("#eab308")
const COLOR_STATUS_RED: Color = Color("#ef4444")

var fighter_data: Dictionary = {}
var is_hovered: bool = false
var is_selected: bool = false

@onready var status_pip: ColorRect = %StatusPip
@onready var portrait_rect: TextureRect = %PortraitRect
@onready var name_label: Label = %NameLabel
@onready var meta_label: Label = %MetaLabel
@onready var style_label: Label = %StyleLabel
@onready var weight_label: Label = %WeightLabel
@onready var record_label: Label = %RecordLabel
@onready var cond_bar: ProgressBar = %ConditionBar
@onready var cond_label: Label = %ConditionLabel
@onready var form_container: HBoxContainer = %FormContainer
@onready var contract_wage_label: Label = %ContractWageLabel
@onready var contract_duration_label: Label = %ContractDurationLabel
@onready var activity_btn: Button = %ActivityButton
@onready var profile_btn: Button = %ProfileButton
@onready var selection_accent: ColorRect = %SelectionAccent

var stylebox: StyleBoxFlat

func _ready() -> void:
	custom_minimum_size = Vector2(1808, 84)
	mouse_filter = Control.MOUSE_FILTER_STOP
	
	stylebox = StyleBoxFlat.new()
	stylebox.bg_color = COLOR_BG_NORMAL
	stylebox.border_color = COLOR_BORDER_DEFAULT
	stylebox.set_border_width_all(1)
	stylebox.set_corner_radius_all(4)
	add_theme_stylebox_override("panel", stylebox)
	
	mouse_entered.connect(_on_mouse_entered)
	mouse_exited.connect(_on_mouse_exited)
	gui_input.connect(_on_gui_input)
	
	activity_btn.pressed.connect(_on_activity_pressed)
	profile_btn.pressed.connect(_on_profile_pressed)
	selection_accent.visible = false

func bind_fighter(data: Dictionary) -> void:
	fighter_data = data
	name_label.text = data.get("name", "Unknown Boxer").to_upper()
	name_label.add_theme_color_override("font_color", COLOR_TEXT_CREAM)
	
	var country = data.get("country_code", "USA")
	var age = str(data.get("age", 20))
	var nickname = data.get("nickname", "")
	meta_label.text = ("\"%s\" · " % nickname if nickname != "" else "") + "%s yrs · %s" % [age, country]
	meta_label.add_theme_color_override("font_color", COLOR_TEXT_MUTED)
	
	style_label.text = "%s\n%s" % [data.get("style", "Out-Fighter"), data.get("stance", "Orthodox")]
	weight_label.text = "%s\n%1.1f lbs" % [data.get("weight_class", "Welterweight"), data.get("current_weight", 147.0)]
	
	var rec = data.get("record", {"w": 0, "l": 0, "d": 0, "ko": 0})
	record_label.text = "%d-%d-%d (%d)" % [rec.w, rec.l, rec.d, rec.ko]
	
	var cond_val: float = data.get("condition", 100.0)
	cond_bar.value = cond_val
	cond_label.text = "%d%%" % int(cond_val)
	
	contract_wage_label.text = "$%d / wk" % data.get("weekly_wage", 800)
	contract_duration_label.text = "%d bouts left" % data.get("bouts_remaining", 4)
	
	_render_form_spark(data.get("last_bouts", ["W", "W", "W"]))
	_update_status_pip(data)
	
	activity_btn.text = data.get("today_activity", "UNASSIGNED")
	if activity_btn.text == "UNASSIGNED":
		activity_btn.modulate = COLOR_GOLD
	else:
		activity_btn.modulate = Color.WHITE

func _render_form_spark(results: Array) -> void:
	for child in form_container.get_children():
		child.queue_free()
	
	for res in results:
		var lbl = Label.new()
		lbl.text = str(res)
		lbl.custom_minimum_size = Vector2(18, 18)
		lbl.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
		lbl.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
		
		var font_col = COLOR_STATUS_GREEN if res == "W" else (COLOR_STATUS_RED if res == "L" else COLOR_TEXT_MUTED)
		lbl.add_theme_color_override("font_color", font_col)
		form_container.add_child(lbl)

func _update_status_pip(data: Dictionary) -> void:
	var cond = data.get("condition", 100.0)
	var planned = data.get("today_activity", "UNASSIGNED") != "UNASSIGNED"
	
	if cond < 50.0 or data.get("is_injured", false):
		status_pip.color = COLOR_STATUS_RED
	elif not planned or cond < 75.0:
		status_pip.color = COLOR_STATUS_AMBER
	else:
		status_pip.color = COLOR_STATUS_GREEN

func _on_mouse_entered() -> void:
	if is_selected:
		return
	is_hovered = true
	var tween = create_tween().set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_OUT)
	tween.parallel().tween_property(stylebox, "bg_color", COLOR_BG_HOVER, 0.12)
	tween.parallel().tween_property(stylebox, "border_color", COLOR_BORDER_HOVER, 0.12)

func _on_mouse_exited() -> void:
	if is_selected:
		return
	is_hovered = false
	var tween = create_tween().set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_OUT)
	tween.parallel().tween_property(stylebox, "bg_color", COLOR_BG_NORMAL, 0.12)
	tween.parallel().tween_property(stylebox, "border_color", COLOR_BORDER_DEFAULT, 0.12)

func _on_gui_input(event: InputEvent) -> void:
	if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
		_on_profile_pressed()

func _on_activity_pressed() -> void:
	activity_change_requested.emit(fighter_data.get("id", ""), activity_btn.global_position + Vector2(0, activity_btn.size.y))

func _on_profile_pressed() -> void:
	fighter_selected.emit(fighter_data.get("id", ""))

class_name GymRosterScreen
extends Control

signal open_scouting_requested
signal open_tryouts_requested
signal inspect_fighter_profile(fighter_id: String)

const COLOR_VOID: Color = Color("#0d0c0b")
const COLOR_GOLD: Color = Color("#f0c233")
const COLOR_TEXT_CREAM: Color = Color("#f5f0e6")
const COLOR_TEXT_MUTED: Color = Color("#a8a29e")

@onready var roster_list_container: VBoxContainer = %RosterListContainer
@onready var empty_state_card: PanelContainer = %EmptyStateCard
@onready var table_header_row: PanelContainer = %TableHeaderRow
@onready var roster_count_label: Label = %RosterCountLabel
@onready var btn_empty_scout: Button = %EmptyScoutButton
@onready var btn_empty_tryout: Button = %EmptyTryoutButton
@onready var btn_header_scout: Button = %HeaderScoutButton

var roster_collection: Array[Dictionary] = []
var active_filter: String = "ALL"
var current_sort_col: String = "NAME"
var sort_ascending: bool = true

func _ready() -> void:
	btn_empty_scout.pressed.connect(func(): open_scouting_requested.emit())
	btn_header_scout.pressed.connect(func(): open_scouting_requested.emit())
	btn_empty_tryout.pressed.connect(func(): open_tryouts_requested.emit())
	_setup_filters()
	refresh_roster_data()

func populate_roster(fighters: Array[Dictionary]) -> void:
	roster_collection = fighters
	refresh_display()

func refresh_display() -> void:
	for child in roster_list_container.get_children():
		child.queue_free()
	
	var total_count = roster_collection.size()
	roster_count_label.text = "ROSTER CAPACITY: %d/8" % total_count
	
	if total_count == 0:
		empty_state_card.visible = true
		table_header_row.visible = false
		btn_header_scout.visible = false
		return
	
	empty_state_card.visible = false
	table_header_row.visible = true
	btn_header_scout.visible = true
	
	var filtered = _apply_filter_and_sort(roster_collection)
	for f_data in filtered:
		var row: FighterRosterRow = preload("res://ui/components/fighter_roster_row.tscn").instantiate()
		roster_list_container.add_child(row)
		row.bind_fighter(f_data)
		row.fighter_selected.connect(func(f_id): inspect_fighter_profile.emit(f_id))

func _setup_filters() -> void:
	var filter_group = %FilterChipsContainer
	for btn in filter_group.get_children():
		if btn is Button:
			btn.pressed.connect(func():
				for b in filter_group.get_children():
					b.set_pressed_no_signal(b == btn)
				active_filter = btn.name.to_upper()
				refresh_display()
			)

func _apply_filter_and_sort(source: Array[Dictionary]) -> Array[Dictionary]:
	var result: Array[Dictionary] = []
	for f in source:
