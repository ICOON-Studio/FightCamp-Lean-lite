Before rejecting a delivery because it "breaks" a real sports rule, verify the rule is current with a web search.
S101's handover told S102 to send Q204 back because "the IJF abolished yuko in 2017"; the IJF REINSTATED yuko for the
LA2028 cycle (Paris Grand Slam 2025), so Q204 was right and merged.

**Why:** rulebooks change every Olympic cycle; a remembered rule can be a cycle stale and would have thrown away correct work.
**How to apply:** one WebSearch on the rule before any send-back or re-pin justified by it; cite the source in the digest.
