Operator, 2026-09-25 (S73), verbatim: "ok go with fictional names and the swap file". Earlier position (superseded):
use real names and "patch them" if challenged; the operator has contacted the UFC.

- Default build: fictional fighters, promotions, belts, logos. Known real sources to move: `featured_real_athletes.json`
  (100 athletes), `real_organizations.json` (18 orgs); grep for the rest (logos, UFC branding in reference clips).
- ONE names file swaps them at launch; a real-names file is never shipped. A test must prove the default shows no real name.
- Steam Workshop: PLAYERS may share name packs (Football Manager / PES model); the STUDIO never uploads, pins, links or
  advertises one. An official pack only if a licence is granted.
- Recommended one paid IP-lawyer consultation before public release (not legal advice from Claude).

**Why:** a takedown can pull the Steam page before any patch; fighter likeness is a separate right from the UFC's.
**How to apply:** built as part of S74's playable build; never re-ask. See [[user_role_ceo_and_lead_dev]].

**AMENDED 2026-09-25 (S75), operator verbatim:** "i want to Keep the real name for the tournaments. We will be
prepared to challenge legally anyone who doubt this ... the use of simple words or initials is freedom of speecch",
then "only name". So real ORGANISATION / federation / tournament names ship (names and initials only - no logos,
belt art, or official/endorsement wording). Real ATHLETES stay fictional by default. S76 restores the 18 org names.

**CONFIRMED 2026-09-25 (S75), operator verbatim:** "keep the swap file, fictional by default , can be added later as
workshop item." FIGHTERS: fictional in shipped data; real names only via the player-installed swap file, later a
Steam Workshop item; studio never ships them. ORGANISATIONS: real names ship (names only). Why the split: athlete
names = right of publicity (Hart v. EA / Keller v. EA 2013 went against EA); org names = trademark, nominative use.
Do not re-ask either.
