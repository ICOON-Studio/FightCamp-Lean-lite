**Operator rule, 2026-09-22: "the agents should have all available information
on existing researches and tools."**

`python Tools/gen_index.py` regenerates `RESEARCH_INDEX.md` at the repo root:
one line per artefact across **789 research documents, 220 Godot tools and 116
drivers**, with what each one is. `--check` exits non-zero when it is stale.

**GREP IT, NEVER READ IT WHOLE** — it is ~214 KB, and reading it costs more than
the exploration it replaces.

**Why it exists:** every task file says "read your task file and only the files
it names". That is a credit rule and it works ([[project_credit_budget_2026-09]]),
but an agent cannot read what it does not know exists. The index closes that gap
without reinstating the 38k-token HANDOFF read.

**How to apply:** every task file gets a `WHAT ALREADY EXISTS` section naming
the two or three greps worth running for that task, plus the standing line that
**a negative result is a result** — paired clip generation, a purchasable
grappling pack and a numbered referee break clock are all already answered NO,
and re-running one wastes a whole pass. Regenerate the index at handover.
