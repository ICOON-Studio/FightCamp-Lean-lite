Operator 2026-09-30: "icons with nice tooltips instead of text"; restated 2026-10-01: "another art direction is use
icons when its possible to skip text (with the necessary toolltip of course)".

**Why:** text-heavy screens read as a prototype (D66 5/10: cluttered, unexplained); icons + tooltips are how AAA
management games stay clean while explaining every number.

**How to apply:** DesignLibrary/GLOSSARY.md "Icon with tooltip" is the instrument (icon + value; hover: title, total,
per-source breakdown). Paste an "Art direction (operator, binding)" section into EVERY UI task brief and check delivered
stills against it before merging. Text labels only where no icon can carry the meaning. Related:
[[feedback_aaa_one_more_turn_wire_everything]].
