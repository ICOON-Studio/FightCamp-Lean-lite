Drift most from UI.gd

  1. Office.gd - 27 own hex, 0 UI.* refs; its own blue-black palette
  2. TV.gd - a whole second palette; 34 files import it, menus included
  3. DarkOverview.gd - own panel/ink/band/tone tables; bands differ from AttrBoard on the same data
  4. CornerSwapCards.gd - 15 hex, a 3rd red #e06060, own card brown
  5. HudRegroup.gd - 13 hex, 0 UI refs, 2 greens 2 reds of its own
  6. Tips.gd - 11 own hex, navy ink on every hover card, 0 UI refs
  7. RosterCards.gd - 12 hex: near-UI paper + 6 tile colours
